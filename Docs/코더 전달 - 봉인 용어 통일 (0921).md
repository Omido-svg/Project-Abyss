# 「봉인」 용어 통일 — 기획 → 코더 (2026-09-21)

슬롯을 사용할 수 없게 만드는 효과의 **이름을 「봉인」 하나로 통일**한다는 전달 문서입니다. 게임플레이 규칙(발동 조건 · 대상 · 지속 · 해제 · 수치)은 바뀌지 않습니다. 요청 사항은 **명칭 통일**뿐입니다.

## 1. 변경 목적

슬롯 사용 불가 효과가 캐릭터마다 다른 이름으로 불리고 있었습니다.

| 캐릭터 | 지금까지의 이름 |
|---|---|
| 유진 | 「봉인」 |
| 히후미 | 「과부화」(슬롯 잠금 의미. 문서에 따라 「과부하」로도 표기) |

같은 개념이 기획 문서 · UI · 코드에서 두 이름으로 갈라지지 않도록 **「봉인」 하나로 통일**합니다.

## 2. 「봉인」 정의

> **봉인 = 슬롯을 사용할 수 없게 만드는 효과의 공통 명칭**

슬롯이 봉인되어 있는 동안 그 슬롯은 사용할 수 없습니다.

「봉인」은 **명칭의 통일**이지 **구현 구조의 통일**이 아닙니다. 하나의 공용 클래스를 만들어 모든 캐릭터가 공유해야 한다는 뜻이 아니며, 캐릭터별 구현은 기존 구조에 맞게 유지해도 됩니다. 플레이어에게 보이는 개념과 기획 용어가 **「슬롯 사용 불가 = 봉인」**으로 맞으면 됩니다.

이미 이 뜻으로 쓰이고 있는 곳(변경 없음)
- 유진 — 적설 표식 발화 · 시한 발화 (4번 참고)
- 감정 증강 「경외」 3티어 「제물(공간)」 — 다리 봉인 (규칙서 14.3)

## 3. 공용 상태이상과의 차이

「봉인」은 힘 · 쇠약 · 보호 · 균열 같은 **공용 N/T 상태이상이 아닙니다.**

| | 공용 상태이상(규칙서 11장) | 봉인 |
|---|---|---|
| 성격 | `상태 N만큼 T턴 부여` 등 공통 문법을 따르는 상태 | 슬롯 사용 불가 현상의 **공통 용어** |
| N/T 공통 상태이상 시스템 | 등록됨 | **등록하지 않음** |
| 공용 상태이상 목록 | 포함 | **추가하지 않음** |
| 독립 항목 중첩 · 합산 규칙(11.1) | 적용 | **자동 적용하지 않음** |
| 공용 상태이상 UI 규칙(값 · 아이콘 · 남은 턴) | 적용 | **자동 적용하지 않음** |

발생 조건 · 대상 · 지속시간 · 해제 조건은 **각 캐릭터 · 스킬의 개별 규칙**을 따릅니다.

## 4. 유진 적용

기존 「봉인」을 **그대로** 사용합니다. 유진이 효과를 통해 상대(또는 지정된) 슬롯을 사용할 수 없게 만드는 상태가 「봉인」입니다.

현재 규칙서에 있는 유진 봉인(참고용 — 바꾸지 않습니다)
- 적설 표식 발화 = 봉인 1턴 (18.1)
- 결투 L 「시한을 정하다」 — 시한 안에 발화하면 적설은 봉인 2턴 (18.4)
- 봉인은 부위 파괴가 아니다 — 전투 한정이며 사망 조건 밖 (개발로그 07-28 확정)

유진의 기존 조건과 작동 방식은 **임의로 변경하지 마세요.**

## 5. 히후미 적용

히후미의 슬롯 잠금 효과에 쓰던 **「과부화」라는 용어는 슬롯 봉쇄 의미에서는 폐기**합니다. 앞으로 히후미가 자기 슬롯을 사용할 수 없게 만드는 효과도 **「봉인」**이라 부릅니다.

| | 표기 |
|---|---|
| 기존 | 과부화로 자기 슬롯이 잠김 |
| 변경 | 해당 슬롯이 봉인됨 |

현재 상태
- 규칙서(정본) 19장에는 히후미 슬롯 잠금 효과가 **아직 없습니다.** 작업 노트(`Docs/작업/히후미.md`)에서 설계 중인 카드 하나(평타 「자기 과부화형」, 가칭)만 이 효과를 씁니다. 수치와 세부 조건은 미확정입니다
- 코드 · UI · 데이터에 히후미 슬롯 잠금을 뜻하는 「과부화」 계열 명칭이 이미 있다면 **표기만 「봉인」으로** 맞춰 주세요. 없다면 이번에 새로 구현할 것은 없습니다

바꾸지 않는 것: 발동 조건 · 봉인되는 슬롯 · 지속 방식 · 해제 조건 · 기타 페널티. 별도 확정이 없는 한 기존 기획 그대로입니다.

**결투 트리 이름 「과부화」(육참골단 / 과부화 / 무난)는 유지됩니다.** 카드 분류명이라 이번 폐기 대상이 아니며, 트리 이름을 바꾸지 마세요. 과부화 계열 효과의 일종으로 「봉인」이 있다는 관계입니다. 폐기되는 것은 **슬롯 잠금을 가리키는 「과부화」라는 용어**뿐입니다.

## 6. 구현 시 주의사항

- **「과부화」와 「봉인」을 서로 다른 슬롯 잠금 상태로 만들지 말 것** — 같은 현상입니다
- **히후미의 슬롯 잠금만 별도의 「과부화」 상태로 구현하지 말 것**
- **「봉인」을 N/T 공용 디버프로 확대 해석하지 말 것** (3번 표 참고)
- **캐릭터별 봉인의 세부 작동 방식까지 억지로 통일하지 말 것**
- **기획에 없는 지속시간 · 해제 조건을 새로 만들지 말 것**
- 이 문서는 **슬롯 사용 불가** 의미의 용어만 다룹니다. 규칙서 3.3~3.5의 「봉인」은 「상대 결투 효과가 발동하지 못함」(결투 효과 게이트)을 가리키는 별개 용법이므로, 이 문서의 「봉인」(슬롯 사용 불가)과 섞어 구현하지 마세요
