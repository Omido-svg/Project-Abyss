## 1. 상태 분류

### Numeric Timed — N + T / 독립 Entry
- 힘
- 쇠약
- 골절
- 보호
- 균열
- 열기
- 침체
- 신속
- 견고
- 무장해제
- 재생
- 지정

규칙:
- 부여 1회마다 독립 Entry
- 살아 있는 N 합산
- T는 Entry별 감소
- `∞` 허용
- 반대 상태는 저장 단계에서 삭제하지 않고 계산 단계에서 대수합

### Presence Timed — T only / max refresh
- 고통
- 공포

규칙:
- N 없음
- 효과 중첩 없음
- 재부여 시 `max(현재 남은 T, 새 T)`

### Bespoke Accumulating
- 출혈
- 표식

규칙:
- Generic N/T storage policy를 적용하지 않음
- 각 캐릭터 장의 누적/발화/감쇠 규칙 사용

### Non-common keyword
- 봉인

규칙:
- 공용 상태이상이 아님
- 스킬/캐릭터가 발동·대상·지속·해제를 직접 소유

## 2. Phase 0에서 확정된 핵심

- Numeric 상태 = independent N/T
- Numeric `∞` 정식 지원 대상
- Presence = T only / max refresh
- Heat = TurnEnd 위세 +N
- Stagnation = TurnEnd 위세 -N
- Regeneration = TurnEnd HP +N AND Stagger +N
- Pain = 활성 중 두 회복 모두 1회 ÷2
- Fear = 활성 중 굴림 위력 -1 고정
- Designation = 실제 표식 적립량에 현재 지정 총합 N 추가
- Swift = 일반 Numeric 상태. 예약 효과는 TurnStart에서 속도 굴림 전에 실제 부여
- 공용 Value / Duration / 동시 Entry 수 상한 없음
- Seal = 공용 상태 아님

## 3. PENDING_CANONICAL

0922 문서에서 `(미정)`인 것은 구현자가 임의 확정하지 않는다.

대표 도메인:
- 다리 조준의 별도 처리
- 증강/아이템으로 최대 빛이 늘어난 경우 전투 시작값
- 일부 적 파괴 스킬/수치/엘리트 절대 스탯
- 탱커 중복 엄호 및 엄호 지속/해제 세부
- 결투 후보 부족 시 quota 처리
- 히후미 일부 신규 카드 수치/임시 키워드
- 감정 증강 일부 카드별 수치
- 아이템/강화 일부 최종값

`PENDING_CANONICAL`은 코드 버그와 구분한다.
