# 전투 시스템 규칙 — 요약 (구현용)

정본은 `전투 시스템 규칙.md`다. 이 문서는 구현할 때 옆에 두고 보는 **숫자 · 순서 · 공식**만 모은 것이다. 둘이 어긋나면 정본이 맞다.
**(미정)** = 아직 정해지지 않은 칸 — 값이 적혀 있으면 임시값이니 데이터로 뺄 것. 스킬 수치는 강화 2회 만렙 기준.

---

## 1. 한 판의 뼈대
- **솔로** — 캐릭터 1명(올라프 · 유진 · 히후미)으로 런 끝까지
- 플레이어 부위 4개(머리 · 왼팔 · 오른팔 · 다리) = 턴당 행동 슬롯 4개
  - 팔 = 공격(평타/결투) · 머리 = 공격 또는 도사림 · 다리 = 도사림 · 위세 = 슬롯 안 씀
- 적 — 잡몹(부위 없음, 1슬롯 × 3굴림) / 엘리트 · 보스(부위 5, 자세별 공격 슬롯 2~4)
- 합 = **굴림 소모전** — 스킬마다 굴림 N개, 하나씩 맞부딪혀 양쪽 소모, 남는 굴림은 일방타격

## 2. 턴 순서
```
[계획 — 누르는 즉시 적용]
 0. 턴 시작: 지난 턴에 예약된 효과(「다음 턴」 부여 · 예약 표식)를 실제로 부여
 1. 속도 굴림 (전 슬롯, 1~6)
 2. 위세 발동 (게이지 ≥ 임계일 때, 즉시 적용)
 3. 준비 행동: 도사림 · 무기 교체(유진 환형 — 안 든 무기 2개 중 선택, 교체는 다음 턴 · 카드 보너스는 그 턴)
 4. 슬롯 배치 · 조준 · 빛 지불
[해결 — 「턴 종료」 이후]
 5. 속도순으로 합 처리 (내 슬롯 + 적 슬롯을 한 풀에)
 6. 턴 종료: 출혈 도트 · 열기 · 재생 · 고조 칸 적립(최종 바 위치 기준) · 상태 지속 −1(0이면 그 항목 제거) → 기세 바 0으로 리셋
    열기 · 재생은 효과를 낸 뒤 지속이 준다
    턴 종료 효과들 사이의 순서 (미정) — 고조는 리셋 전 바로 계산한다는 것만 확정
```

## 3. 교환 하나의 계산
```
판정값 = 기본위력 + 소스 굴림 + 속도 보정(빠른 쪽만: 속도차 1~5 → +1 / 6 이상 → +2) + 판정 버프
기본위력 = 곡선[굴림 수] + 빛 × 2        곡선 = {1:20, 2:12, 3:11, 4:9, 5:8}
  · 유진 = 11 고정 (앞면 = 곡선[코인 수] + 크리값 / 뒷면 = 11 + 2)
  · 히후미 = 곡선 + 빛 × 2 + 1
동률 → 위력 굴림만 다시 (속도 고정)
높은 쪽이 교환 승리 → 굴림 값만큼 효과
```

| 소스 | 값 |
|---|---|
| 올라프 · 적 | 균등 1~8 |
| 유진 | 코인 — 무기가 코인 수 · 앞면 확률 · 크리값을 정한다 |
| 히후미 | 친치로 — 아라시 · 시고로 +18 / 목 = 남은 눈 / 꽝 = 가장 작은 눈 / 1 · 2 · 3 = 대실패(확정 패배 + 자해 60 → 뼈 60 + 반격 굴림 +1, 어디서 나오든 같다. 카드가 직접 다시 정의하면 카드가 우선) |

**스킬 색**
| 색 | 이긴 교환 |
|---|---|
| RED | 상대에게 체력 피해 + 흐트러짐 피해 (= 굴림 값 × 상대 내성) |
| BLUE | 상대에게 흐트러짐 피해(× 내성) + 자신 흐트러짐 회복(= 굴림 값, 고정) |

## 4. 피해 처리 순서
```
1. 흐트러짐 피해 = 값 × 흐트러짐 내성
2. 체력 피해   = 값 × 체력 내성 (창이 열려 있으면 모든 타입 ×2 로 덮어쓰기 — 1에서 방금 열린 창 포함)
3. − 받는 피해 N (flat)
4. 캐릭터 고유 증감 (올라프 광기 등)
5. 버림, 최소 1
6. 방어도 흡수 (1:1, 초과분만 다음으로)
7. 부위 체력 − 피해, 전체 체력 − 피해 (이중 차감)
   · 부위는 1에서 멈춘다(약화). 일반 파괴 = 파괴 권한 피해가 「이미 약화된」 부위의 남은 체력을 0으로 만들 때 (약화 여부는 피해 전 상태)
   · 처형 = 피해량이 충분하면 같은 타격 안에서 약화 → 파괴. 남은 체력을 무시하는 즉사나 무조건 파괴가 아님
```
- 곱연산은 **내성(×0.5 / ×1 / ×2)과 명시된 ÷2 두 개**뿐. 나머지는 전부 flat
- 방어도로 다 막아도 바는 밀린다. 흐트러짐 피해는 방어도와 무관

## 5. 핵심 숫자
| 항목 | 값 |
|---|---|
| 플레이어 | 부위 100 × 4 · 전체 600 (미정) · 흐트러짐 350 |
| 보스 | 부위 150 × 5 · 전체 1,500 (미정) · 흐트러짐 400 |
| 잡몹 | 3 × 135 또는 4 × 101 (미정) · 흐트러짐 100 |
| 빛 | 시작 = 현재 최대치까지 전량(기본 3) · 턴 시작 +1 · 최대 3 · 처치 +1 · 적 부위 약화 +1 |
| 기세 바 | −100 ~ +100 · 매 턴 0 리셋 · 임계 ±30 / ±70 |
| 바 이동 | 이긴 교환 +20 · 결투 대 결투 교환 승리 +40 |
| 고조 칸/턴 | 짓누름 10 · 우세 5 · 중립 2 · 열세 0 · 짓눌림 0 |
| 열광 문턱 | 4 → 8 → 10 칸 (레벨 0~3) |
| 레벨업 | 빛 최대 +1 · 빛 전량 회복 · 감정 증강 3중 1. 열광 3 이후 고조는 소멸 |
| 적 고조 · 열광 | 거울 구간(내 짓눌림 = 적 짓누름 10 …) · 같은 문턱 · 레벨업 = 빛 최대 +1 · 전량. 일반 몹 증강 없음 · 엘리트/보스 = 종류별 고정 열광 증강 |
| 위세 충전 | 합 시작 +1 · 교환 +1 · 처치 +5 · 전투 시작 0 |
| 위세 임계 | 형마다 (40~70, 기준 50) |
| 흐트러짐 창 | 0이 되면 체력 내성 전부 ×2(덮어쓰기) — 깨진 턴의 남은 처리 + 다음 턴 전체 → 끝나면 100% 회복 |
| 방어도 | 전투 내내 누적, 전투 끝나면 0 |
| 로드아웃 | 평타 3 · 결투 3 · 도사림 3 · 위세 1 · 패시브 |

## 6. 게이트와 트리거
- **결투 대 결투 게이트** — 결투 성립은 개별 트리거가 아니라 결투 효과를 사용할 수 있게 하는 공통 게이트다. 상대가 평타면 결투는 위력만 남는다. **게이트 안 = 그 결투 카드의 효과 전체**(전투 시작시 · 사용시 · 승리시 · 패배시 · 고유 효과)
- 「피해 처리 후」는 트리거가 아니라 조건을 보는 시점 — 피해 처리 → 약화 · 파괴 · 처치 · 흐트러짐 반영 → 조건 검사. 추가타는 원래 카드의 「피해 처리 후」 효과를 상속하지 않는다
- 다리를 공격으로 조준하면 합이 성립하지 않고 일방타격(예외 없음) · 도사림은 조건 · 빛 · 슬롯이 허용하는 한 매 턴 사용(공통 전투당 제한 없음)
- 게이트가 열린 뒤 상대 굴림이 먼저 끝나도 남은 굴림의 **사용시**는 발동한다. 일방타격에는 실제 교환이 없으므로 **승리시 · 패배시**는 발동하지 않는다
- **적 결투 수가 곧 플레이어 결투 카드의 on/off다** — 적 설계 때 먼저 정할 것

| 트리거 | 조건 |
|---|---|
| 전투 시작시 | 스킬 합 시작 순간, 첫 굴림 전 카드당 1회. 상대 스킬 교체 · 소비량에 따른 굴림 수 확정처럼 구조를 먼저 정할 때만 사용 |
| 사용시 | 그 굴림을 실제 사용하는 순간, 판정 전. 굴림별 발동이며 일방타격 굴림에도 적용 |
| 승리시 | 실제 교환이 발생했고 그 교환에서 이겼을 때. 일방타격 제외 |
| 패배시 | 실제 교환이 발생했고 그 교환에서 졌을 때 |
| 합 종료시 | 그 스킬의 합이 끝났을 때 — 합 전체 결과(진 교환 수 등)를 조건으로. 합이 없으면 없음 |
| 도사림 발동시 | 굴림 없는 도사림을 발동하는 순간 카드당 1회 |

- `매칭시` 트리거는 폐기한다. 단순 자원·상태 효과를 편의상 `전투 시작시`로 올리지 않는다
- 합 단위로 판정하는 건 **「합 종료시」트리거뿐**이다. 위세 충전 · 유진 낙일 「남은 굴림 삭제」를 포함해 나머지는 전부 교환 단위
- 합 도중 조준 부위가 파괴되거나 처치되면 그 슬롯의 남은 굴림은 소멸
- **합 성립** — 내 공격 슬롯이 상대의 공격 슬롯을 조준하면 합(상대가 누구를 노렸든 · 속도 무관). 한 상대 슬롯엔 합이 하나 — **마지막으로 조준한** 내 슬롯이 가져가고 나머지는 일방타격. 합이 없는 공격은 전부 일방타격
- **적의 부위 파괴** — 파괴 스킬을 가진 적(일부 잡몹 · 엘리트 · 보스)만 한다. 기세 바와 무관

## 7. 기세 바 이벤트
| 사건 | 조건 | 효과 |
|---|---|---|
| 짓누름 보상 | 지난 턴을 B ≥ +70으로 끝냄 | 다음 턴 빛 +1(즉시, 최대치까지) |
| 발악 | 지난 턴을 B ≤ −70으로 끝냄 | 다음 턴 판정값 +1(노려보기와 같은 종류) — 적은 엘리트 · 보스만 |
| 고조 적립 | 턴 종료 | 그 턴 최종 구간의 칸 |

## 8. 상태이상
| 종류 | 문법 | 해당 |
|---|---|---|
| 수치형 | `N만큼 T턴` | 힘 · 쇠약 · 골절 · 보호 · 균열 · 열기 · 신속 · 견고 · 무장해제 · 재생 · 지정 |
| 값 없는 지속형 | `T턴` | 고통 · 공포 |
| 고유 누적 | 스택 가산 | 출혈 · 표식 |

- **수치형** — 부여마다 독립 항목 · 효과 = 살아 있는 N 총합 · 턴 종료 시 항목마다 T −1, 0이면 그 항목만 제거. 표시 = N 총합 / 가장 긴 T
- **지속 ∞** — 턴 종료 시 자연 감쇠하지 않는다(제거 · 비활성 조건과 전투 종료는 적용). 표시는 `값 · 아이콘 · 남은 턴`, 영구면 턴 자리에 `∞` (예: `2 · [힘] · ∞`)
- **값 없는 지속형** — 효과 중첩 없음 · 재부여 시 남은 지속 = max(현재, 새로)
- **즉시 vs 다음 턴 예약** — 예약은 턴 시작 → 실제 부여 → 속도 굴림. 즉시 부여한 1턴 상태는 그 턴 종료 시 소멸
- **반대 상태는 서로 지우지 않는다** — 계산할 때만 대수합
  - 굴림 위력 보정 = 힘 − 쇠약 (공포가 걸려 있으면 −1) / 골절 · 신속은 최댓값에만 따로
  - 체력 피해 = 원 피해 + 균열 − 보호 / 흐트러짐 피해 = 원 피해 + 무장해제 − 견고 / 턴 종료 위세 = 열기 − 침체
- 열기 = 턴 종료마다 위세 +N / **침체 = 턴 종료마다 위세 −N** / 재생 = 턴 종료마다 체력 N + 흐트러짐 N (둘 다)
- 고통 = **체력 · 흐트러짐 회복 둘 다** 절반(÷2, 버림 · 최소 1) / 공포 = 상대 굴림 위력 −1 고정
- 지정 = 지정된 부위에 표식이 쌓일 때마다 +N(지정 총합)
- 은신 N(유진) = 적이 그 부위를 조준 못 함 · 그 부위가 **스킬 행동 하나**를 마칠 때마다 −1(굴림 수 무관) · 턴 종료로 안 줄어듦 · 다음 턴 부여는 이번 턴에 성립한 조준을 취소하지 않음 · 한 스킬의 굴림별 부여는 누적 · 다음 턴 예약은 다음 턴 시작(적 조준 전)에 실제 은신, 그 전에 부위가 파괴되면 소멸 · 은신 부위 슬롯도 적 스킬을 조준해 합을 붙일 수 있다(결투 대 결투 정상 성립) · 재부여 처리 (미정)
- 출혈 = 턴 종료 시 스택만큼 피해 → −1 · 재부여 시 가산 · 자연 지속 없음
- 표식 = 감쇠 없음 · 적립 순간 44 이상이면 즉시 발화 · 초과분 이월 없음(예외: 유진 성장 집행 3단계) · 예약 표식은 턴 시작(속도 굴림 전)에 적립
- 낙점(유진) = 실제 교환에서 **이긴 굴림**마다 붙는 기본 표식(무기별 부여량). 일방 공격은 승리가 아니라 안 붙음 · 카드 효과 표식은 낙점과 별도로 더함
- 덫(유진) = 폭발 덫 · 공명 덫 · 전염 덫. 적 부위에 쌓고, 그 부위 표식이 44에서 발화할 때 함께 발동하며 그 종류를 전부 소비(폭발 = 스택 비례 확정 피해 / 공명 = 발화 자체를 강화 발화로 / 전염(2턴) = 다른 적 무작위 최대 2명에게 표식 N, 그 발화도 전염을 잇고 재감염 허용) · 덫은 표식을 주지 않음 · 처리 순서: 승리 → 덫 설치 → 낙점 → 발화 → 방금 단 덫도 발동
- 감정 증강의 **고유 지속 효과는 공용 상태이상이 아니다** — 연민 「재생」 · 「흐트러짐 재생」은 이름만 같다
- **상한 없음** — 값 · 지속 · 항목 수 전부. 밸런스는 부여량 · 지속 · 빈도 · 비용으로 잡는다

## 10. 놓치면 조용히 틀리는 것
1. 바는 **매 턴 0으로 리셋** — 누적 아님
2. 기세 바 **데미지 배율은 없다**
3. 창은 **덮어쓰기**(×2 세팅)지 곱하기가 아니다
4. 타격 타입은 **굴림 단위**(유진만 무기 단위)
5. 약화 · 파괴 판정은 **피해 전 상태** — 한 타격이 약화와 파괴를 동시에 못 한다. 「약화 또는 파괴 시」 보상은 **타격당 1회**
6. 부위 회복은 **체력만** 올린다(상태는 정비 · 연민 부위 재생만)
7. 모든 체력 회복 = 전체 +N **과** 최저 부위 +N (파괴된 부위 제외). 약화 부위도 체력은 오르고, 오른 만큼 파괴가 늦어진다
8. 문서의 스킬 수치 = **만렙**. 기본값은 따로
9. 감정 증강은 **전투 한정**
10. 적의 결투 개수를 먼저 정할 것
11. 유진 살수의 감 **재굴림은 자동**(슬롯 지정), **패 보기는 결투 도중 선택 UI** — 둘의 흐름이 다르다
12. 빛 회복 카드는 반드시 대가가 붙어 있다
13. 반대 상태이상은 **서로 지우지 않는다** — 힘 3 · 쇠약 2면 보정 +1, 쇠약이 끝나면 다시 +3
14. 표식 발화는 **따로 도는 페이즈가 아니다** — 적립되는 순간 판정한다(예약 표식도 턴 시작 적립 순간)
