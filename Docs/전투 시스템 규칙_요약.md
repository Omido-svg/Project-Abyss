# 전투 시스템 규칙 — 요약 (구현용)

정본은 `전투 시스템 규칙.md`다. 이 문서는 구현할 때 옆에 두고 보는 **숫자 · 순서 · 공식**만 모은 것이다. 둘이 어긋나면 정본이 맞다.
**(미정)** = 아직 정해지지 않은 칸 — 값이 적혀 있으면 임시값이니 데이터로 뺄 것. 스킬 수치는 강화 2회 만렙 기준.

---

## 1. 한 판의 뼈대
- **솔로** — 캐릭터 1명(올라프 · 유진 · 히후미)으로 런 끝까지
- 플레이어 부위 4개(머리 · 왼팔 · 오른팔 · 다리) = 턴당 행동 슬롯 4개
  - 팔 = 공격(평타/결투) · 머리 = 공격 또는 도사림 · 다리 = 도사림 · 위세 = 슬롯 안 씀
- 적 — 잡몹(부위 없음, 1슬롯 × 3굴림) / 엘리트 · 보스(부위 5, 자세별 공격 슬롯 2~4)
- 합 = **굴림 소모전** — 스킬마다 굴림 N개, 하나씩 맞부딪혀 양쪽 소모, 남는 굴림은 일방타격

## 2. 턴 순서
```
[계획 — 누르는 즉시 적용]
 1. 속도 굴림 (전 슬롯, 1~6)
 2. 위세 발동 (게이지 ≥ 임계일 때, 즉시 적용)
 3. 준비 행동: 도사림 · 무기 교체(유진 환형 — 효과는 다음 턴)
 4. 슬롯 배치 · 조준 · 빛 지불
[해결 — 「턴 종료」 이후]
 5. 속도순으로 합 처리 (내 슬롯 + 적 슬롯을 한 풀에)
 6. 턴 종료: 도트 · 재생 · 고조 칸 적립(최종 바 위치 기준) · 1턴 상태 만료 → 기세 바 0으로 리셋
    턴 종료 효과들 사이의 순서 (미정) — 고조는 리셋 전 바로 계산한다는 것만 확정
```

## 3. 교환 하나의 계산
```
판정값 = 기본위력 + 소스 굴림 + 속도 보정(빠른 쪽만, (내 속도 − 상대 속도) × 1, ±2 상한) + 판정 버프
기본위력 = 곡선[굴림 수] + 빛 × 2        곡선 = {1:20, 2:12, 3:11, 4:9, 5:8}
  · 유진 = 11 고정 (앞면 = 곡선[코인 수] + 크리값 / 뒷면 = 11 + 2)
  · 히후미 = 곡선 + 빛 × 2 + 1
동률 → 위력 굴림만 다시 (속도 고정)
높은 쪽이 교환 승리 → 굴림 값만큼 효과
```

| 소스 | 값 |
|---|---|
| 올라프 · 적 | 균등 1~8 |
| 유진 | 코인 — 무기가 코인 수 · 앞면 확률 · 크리값을 정한다 |
| 히후미 | 친치로 — 아라시 · 시고로 +18 / 목 = 남은 눈 / 꽝 = 가장 작은 눈 / 1 · 2 · 3 = 대실패(확정 패배 + 자해 60) |

**스킬 색**
| 색 | 이긴 교환 |
|---|---|
| RED | 상대에게 체력 피해 + 흐트러짐 피해 (= 굴림 값 × 상대 내성) |
| BLUE | 상대에게 흐트러짐 피해(× 내성) + 자신 흐트러짐 회복(= 굴림 값, 고정) |

## 4. 피해 처리 순서
```
1. 흐트러짐 피해 = 값 × 흐트러짐 내성
2. 체력 피해   = 값 × 체력 내성 (창이 열려 있으면 모든 타입 ×2 로 덮어쓰기)
3. − 받는 피해 N (flat)
4. 캐릭터 고유 증감 (히후미 짓눌림 반감 등)
5. 버림, 최소 1
6. 방어도 흡수 (1:1, 초과분만 다음으로)
7. 부위 체력 − 피해, 전체 체력 − 피해 (이중 차감)
   · 부위는 1에서 멈춘다(약화). 파괴는 파괴 권한 + 「이미 약화된」 부위만 (판정은 피해 전 상태)
```
- 곱연산은 **내성(×0.5 / ×1 / ×2)과 명시된 ÷2 두 개**뿐. 나머지는 전부 flat
- 방어도로 다 막아도 바는 밀린다. 흐트러짐 피해는 방어도와 무관

## 5. 핵심 숫자
| 항목 | 값 |
|---|---|
| 플레이어 | 부위 100 × 4 · 전체 600 (미정) · 흐트러짐 350 |
| 보스 | 부위 150 × 5 · 전체 1,500 (미정) · 흐트러짐 400 |
| 잡몹 | 3 × 135 또는 4 × 101 (미정) · 흐트러짐 100 |
| 빛 | 시작 3 · 턴 시작 +1 · 최대 3 · 처치 +1 · 적 부위 약화 +1 |
| 기세 바 | −100 ~ +100 · 매 턴 0 리셋 · 임계 ±30 / ±70 |
| 바 이동 | 이긴 교환 +20 · 결투 대 결투 교환 승리 +40 · 발악이면 ×2 |
| 고조 칸/턴 | 짓누름 10 · 우세 5 · 중립 2 · 열세 0 · 짓눌림 0 |
| 열광 문턱 | 4 → 8 → 10 칸 (레벨 0~3) |
| 레벨업 | 빛 최대 +1 · 빛 전량 회복 · 감정 증강 3중 1 |
| 위세 충전 | 합 시작 +1 · 교환 +1 · 합 승리 +2 · 처치 +5 · 전투 시작 0 |
| 위세 임계 | 형마다 (40~70, 기준 50) |
| 흐트러짐 창 | 0이 되면 1턴간 체력 내성 전부 ×2(덮어쓰기) → 끝나면 100% 회복 |
| 방어도 | 전투 내내 누적, 전투 끝나면 0 |
| 로드아웃 | 평타 3 · 결투 3 · 도사림 3 · 위세 1 · 패시브 |

## 6. 게이트와 트리거
- **결투 대 결투 게이트** — 결투 효과(승리 · 패배 메리트 둘 다)는 **양쪽이 결투로 맞부딪힌 교환에서만** 발동. 상대가 평타면 결투는 위력만 남는다
- **적 결투 수가 곧 플레이어 결투 카드의 on/off다** — 적 설계 때 먼저 정할 것

| 트리거 | 조건 |
|---|---|
| 사용시 | 스킬을 낸 순간 |
| 매칭시 | (결투) 결투 대 결투 게이트만 서면 — 일방타격도 인정 |
| 승리시 | 그 굴림이 실제로 맞붙어 이겼을 때 (결투는 일방타격 제외, 평타는 포함) |
| 패배시 | 그 굴림이 졌을 때 |

- 합 승리(다수결)는 **위세 충전 보너스**와 **유진 낙일의 남은 굴림 삭제** 두 곳만 쓴다. 나머지는 전부 교환 단위
- 합 도중 조준 부위가 파괴되거나 처치되면 그 슬롯의 남은 굴림은 소멸

## 7. 기세 바 이벤트
| 사건 | 조건 | 효과 |
|---|---|---|
| 발악 | 지난 턴을 B ≤ −70으로 끝냄 | 이번 턴 미는 양 ×2 (적은 엘리트 · 보스만 · 히후미는 받는 피해 ½로 치환) |
| 적 파괴 스킬 | 플레이어 B ≤ −70 인 순간 | 엘리트 · 보스가 약화된 부위를 끊을 수 있음 |
| 고조 적립 | 턴 종료 | 그 턴 최종 구간의 칸 |

## 8. 상태이상 누산
- 크기형(그 턴만): 힘 · 쇠약 · 공포 = **전체 이동, 대수합** / 골절 · 신속 = **최댓값, 따로 누산**
- 보호 · 균열 = 받는 피해 ∓N / 열기 = 턴당 위세 +N
- 지속형(스택 = 턴): 재생 · 고통
- 상한은 키워드별(3~4). 신속은 다음 턴부터 적용
- 견고 · 무장해제 (미정)

## 9. 캐릭터 한 줄
| | 소스 | 자원 | 파괴 권한 | 한 줄 |
|---|---|---|---|---|
| 올라프 | 주사위 | 출혈(부위별 스택 · 도트 · 폭발) · 광기(상한 8, 4당 위력 +1 · 받는 피해 +1) | 파괴형 결투 | 쌓아서 터뜨린다 |
| 유진 | 코인 | 표식(44에서 무기별 발화) · 지정 · 살수의 감(매 턴 +1, 재굴림 · 추가타 · 패 보기) | 낙일(처형) | 무기를 골라 처형한다 |
| 히후미 | 친치로 | 뼈(받은 피해 1:1, 500 = 만개) · 반격 굴림(합 종료 후 한 번) | 골단 만개 반격 | 맞아서 모으고 되갚는다 |

## 10. 놓치면 조용히 틀리는 것
1. 바는 **매 턴 0으로 리셋** — 누적 아님
2. 기세 바 **데미지 배율은 없다**
3. 창은 **덮어쓰기**(×2 세팅)지 곱하기가 아니다
4. 타격 타입은 **굴림 단위**(유진만 무기 단위)
5. 약화 · 파괴 판정은 **피해 전 상태** — 한 타격이 약화와 파괴를 동시에 못 한다. 「약화 또는 파괴 시」 보상은 **타격당 1회**
6. 부위 회복은 **체력만** 올린다(상태는 정비 · 연민 부위 재생만)
7. 모든 체력 회복 = 전체 +N **과** 최저 부위 +N
8. 문서의 스킬 수치 = **만렙**. 기본값은 따로
9. 감정 증강은 **전투 한정**
10. 적의 결투 개수를 먼저 정할 것
11. 유진 살수의 감 **재굴림은 자동**(슬롯 지정), **패 보기는 결투 도중 선택 UI** — 둘의 흐름이 다르다
12. 빛 회복 카드는 반드시 대가가 붙어 있다
