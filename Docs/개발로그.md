## 2026-07-23 — 빛(에너지) 경제 전면 확정 + 시뮬 v1.5 재측정

7-21에 걸어둔 시작점(추가 획득 요건)부터 시작해 **빛 경제를 한 세션에 전부 닫았다.** 이후 시뮬레이터를 누적형으로 개정(v1.5)해 결투 푸시 재측정까지 완료.

### 확정된 규칙 (전부 2026-07-23)
- **최대치 증가 시 전량 회복** — 상한이 늘어나는 순간 새 최대치까지 가득. 파생 주의: 전투 중 최대치 상승 효과 = 사실상 "빛 N 획득" 겸용
- **전투 시작 빛 = 3 (가득)** — 잡몹전은 풍족한 소탕전, 저축 긴장은 보스전에서 발현 (기세 바와 같은 결)
- **충전 타이밍 = 턴 시작 시 +1**
- **기본 상한 = 3** — "비용 3 시그니처 = 전 재산" 등식
- **극단 진입 시 전량 회복** (사용자 안) — 짓누르든 짓눌리든, 플레이어 전용, 중립 복귀로 재무장. 짓눌렀을 때 회복이 "바 미느라 빛을 다 쓴 채 클라이맥스 창을 맞는" 구멍을 메움. 라오루 감정 레벨업의 번역(최대치 대신 회복 이벤트로 — 기세 바에 최대치를 걸면 축 분리가 깨져서 기각)
- **처치 시 +1 / 적 부위 약화 시 +1** (플레이어 전용) — "잡몹전의 처치 = 보스전의 부위" 평행. 수입원은 여기서 동결
- **부위 파괴 시 +1 = 채택 안 함** (시뮬 판정 — 아래)

### 시뮬 v1.5 (CombatSim 개정)
전량 회복 → 누적형 전환 + 극단 회복/처치/약화/파괴(ON/OFF) 구현. 신규 지표: 빛 수입 내역·증발량(포화 지표)·결투 시전 수·조용한 판.

### 재측정 결과 (보스전 3000회 스윕)
1. **결투 푸시 10 유지.** 7-21 예측("빈도 반감 → 조용한 판 40~50%")은 빗나감 — 결투 시전 실측 턴당 1.6회, 조용한 판은 오히려 25% → 15% 하락(극단 회복의 되먹임). 짓눌림(나) 32%·즉사 2.2%로 건강 범위
2. **빛 포화 아님** — 증발 판당 0.95. "수입원 4개 = 상시 가득" 걱정은 기우 (상한 3이 작고 결투가 계속 소비)
3. **파괴 +1 기각** — ON 시 수입 +0.37 중 +0.31 증발(85%). 극단 회복 직후 이중 지급 예측이 수치로 확인됨
4. **잡몹전 정상** — 3마리 3.6턴/승률 99.5%, 처치 수입 거의 전액 실수령. 4마리 5.0턴/87%로 난이도 다이얼 작동
5. **신규 관찰: 보스전 플레이어 승률 45% → 54%** (플레이어 전용 수입 효과)

### 보스 다이얼 스윕 → 절대 튜닝은 기각, 구조 판정만 채택 (사용자 결정)

살아남은 구조 판정(상대 비교라 성장 무관): **부위 체력 = 길이·승률만 움직이는 깨끗한 다이얼**(클라이맥스 프로필 불변 — 축 분리가 적 쪽에서도 성립) / **위력 = 교환 승률에 붙어 전부를 건드림**(짓누름 급감·즉사 상승) → 위력은 중간보스/메인보스 난이도 층 가르기용으로 아껴둠.

## 2026-07-21 — 빛(에너지) 상한 논의 재개, 결정은 보류

짧은 세션. **"빛" = 에너지(코스트 자원)의 사용자 호칭**이다(문서엔 전부 "에너지"로 적혀 있고, `전투 시스템 규칙.md`에 *"라이브러리 오브 루이니아의 '빛'과 같은 층위"*라고 한 번 나옴). 이 어긋남 때문에 오늘 문서 검색이 한 번 헛돌았음 — **용어를 하나로 통일하든지, 규칙 문서에 호칭 병기를 해두는 게 좋겠음.**

### 확인된 것 (기존 확정 재확인)
- 비용 티어 **1 / 2 / 3** 확정 (2026-07-20)
- **누적형(매 턴 +1)으로 전환** 결정됨. 비용 차등이 의미를 가지려면 저축이 가능해야 함
- **상한 ≥ 3**은 논리적으로 강제됨 (비용 3짜리를 못 쓰면 티어가 성립 안 함)

### 사용자 안 — 기본 3에서 시작 + 최대치를 늘리는 수단을 따로 만든다
`전투 시스템 규칙.md`의 *"최대치 상승은 증강의 축으로 둔다"*(증강 설계 원칙의 시스템 자원 목록에 에너지가 들어감)와 이미 맞물려 있음. 증강 외 경로(정비 노드? 아이템?)를 열지는 미정.

- ⚠ **"상한을 3 → 5로 올리자고 Claude가 제안했다"는 기억이 있으나 문서에 기록이 없다.** 대화에서 오갔지만 로그에 안 적힌 채 세션이 끝난 것으로 보임 — 확언 불가. **에너지 자체가 누락됐던 7-20 사건과 같은 패턴**이므로 결정은 그때그때 적을 것

### ▶ 내일 시작점 — 추가 획득 요건부터
**턴당 +1 말고 빛을 추가로 버는 경로.** 이걸 먼저 잡아야 하는 이유: 수급이 +1 하나뿐이면 비용 3짜리는 무조건 3턴 대기라 **티어가 "대기 턴 수"로만 읽히고**, 상한 숫자(3이든 5든)에 의미가 안 생김.

- ⚠ **스노볼 금지** — "합에 이기면 +1" 류로 채우면 이기는 쪽이 더 벌어 더 이김. **위세 충전에서 이미 겪고 고친 실패**(구 위세 = 합 승리 시에만 충전 → 역전 도구가 아니라 스노볼)
- **기세 바 코어와 직결**: 정체성이 "짓눌렸다가 역전"인데 빛이 이길 때 차면 짓눌린 쪽에 역전 자원이 없음. 맞을 때 차면 짓눌림이 다음 한 방의 연료가 됨
- 후보 4종: ① 맞았을 때(코어에 가장 충실, 올라프 "몰릴수록 강해짐"과 직결) ② 수비 굴림으로 받아냈을 때(평타의 세 번째 존재 이유) ③ 자기 부위 파괴·약화 시(큰 단위 보상, 부위 상실이 순수 손실이 아니게 됨) ④ 합 시작 시 소량(승패 무관 기본 수급 — 위세가 쓴 해법)
- 남은 것: **몇 개를 섞을지 + 각각 얼마인지** → 그게 정해져야 상한 3이 빡빡한지 널널한지 판단됨

## 2026-07-20 (2차) — 전투 시뮬레이터 구축 + 1차 수치 검증

예정대로 Excel VBA 전투 시뮬레이터를 만들고 첫 스윕을 돌렸다. **문서의 확정값 중 하나가 검증되고, 셋이 반증됐다.**

### 0. 만든 것
`스테이지 맵 기획_계산기.xlsm`에 **`CombatSim` 모듈 + "전투 시뮬" 시트** 추가. 맵 생성기와 같은 방식(시트 버튼 `시뮬 실행`, COM 자동 실행용 `silent` 옵션).
- **파라미터를 전부 시트 셀로 뺐다** — 매크로를 안 고치고 수치만 바꿔 돌릴 수 있음. 바 수치·배율·위력·굴림 개수·체력·RNG 소스 상수·위세 충전량까지 전부
- 구현: 굴림 소모전 / 합 승리 다수결 / 남은 굴림 일방타격 / 파괴·처치 시 굴림 소멸 / 기세 바 3구간 배율 / 발악(김삿갓은 뎀감 치환) / 결투 푸시(결투 대 결투 한정) / 에너지 / 부위 3단계 + 70% 가중 타겟팅 / 보스 3자세 로테이션 + 파괴 눈덩이 / 세 RNG 소스
- **미구현(v2로)**: 캐릭터 고유 엔진(출혈·광기·뼈·취약·처형), 도사림 효과, 위세 효과 자체, 방어도. 위세는 **충전 속도만** 측정

### 1. [검증됨] 기본 교환 승률 50%
대칭 조건(양쪽 평타, 기본위력 동일)에서 올라프 = **0.4925~0.500**. 2026-07-19 확정이 그대로 성립.

### 2. [반증] 유진 "약 37.5%"는 재현되지 않는다
| 속도 계수 | 올라프 | 유진 | 김삿갓 |
|---|---|---|---|
| 0 | 0.500 | **0.252** | 0.337 |
| 0.5 | 0.493 | 0.327 | 0.393 |
| 1 | 0.492 | 0.420 | 0.436 |

- 순수 소스 대결(계수 0)에서 유진은 **25.2%**다. 코인 뒷면 값이 적 굴림 범위 **아래**에 깔리면 뒷면은 전부 패배 → 승률이 크리 확률(25%)과 정확히 같아진다
- **즉 37.5%는 소스의 고정 속성이 아니라 "뒷면 값이 적 굴림 범위 어디에 놓이는가"의 함수다.** 이건 설계 레버이지 상수가 아님 → 규칙 문서의 "약 37.5%" 표기는 조건을 명시하도록 고쳐야 함
- 김삿갓 0.337도 "올라프와 유진 사이"라는 서술과는 맞지만, **50%보다 한참 아래**다(친치로 평균 2.85 < d6 3.5). 확정된 "김삿갓 = 소수 고위력"의 근거가 수치로 확인됨

### 3. [신규] 속도 계수 = 캐릭터 정체성 강도의 마스터 다이얼
위 표의 가로축이 그것이다. **속도 보정이 커질수록 모든 소스가 50%로 끌려간다**(유진 25% → 42%). 속도차가 위력 굴림 폭보다 크면 소스 분포가 묻히기 때문.
- 지금까지 속도 계수는 "임시값 ×1, 추후 튜닝"으로만 적혀 있었는데, 실제로는 **세 캐릭터의 색이 얼마나 진하게 나오는지를 혼자 결정하는 값**이었다. 위력 절대 스케일과 반드시 같이 잡아야 함

### 4. [결정] 적도 에너지(결투)를 가져야 한다 — 미결정 사항 해소
보스전 2000회, 적 에너지 OFF/ON 비교:

| 적 에너지 | 전투 길이 | 플레이어 승률 | 결투 대 결투 합 | 짓눌림(적/나) |
|---|---|---|---|---|
| OFF | 5.24턴 | 98% | **0.00회** | 92% / 0.1% |
| ON | 5.08턴 | 45% | 9.31회 | 59% / 45% |

- **적이 결투를 안 걸면 결투 푸시가 한 번도 발동하지 않는다.** "결투 효과는 결투끼리만"이 그대로 적용되기 때문 → *결투 승리가 바를 움직이는 유일한 변수*라는 확정이 **보스전에서 통째로 사문화**되고, 심리전 3층 구조(결투로 받기/평타로 받기/회피)도 성립하지 않음
- 잡몹전에서도 동일(잡몹은 평타만 → 결투 합 0회). **결투 푸시는 사실상 "적이 결투를 걸 때만 존재하는 규칙"**이었음
- → **적도 에너지를 갖는다.** 보스 3자세와 이중 규제가 될 거란 우려는 기우 — 자세는 *슬롯 수*를, 에너지는 *그 슬롯에 뭘 넣는지*를 정하므로 층이 다름

### 5. [반증] 짓눌림은 클라이맥스가 아니라 일상이 됐다
결투 푸시 스윕(보스전, 적 에너지 ON):

| 결투 푸시 | 길이 | 짓눌림(적) | 짓눌림(나) | 둘 다 없는 판 | 즉사 위험 |
|---|---|---|---|---|---|
| 0 | 9.35턴 | 51% | 11% | 44% | 1% |
| 5 | 8.55턴 | 54% | 27% | 34% | 2% |
| **10** | **8.08턴** | **60%** | **37%** | **25%** | **4%** |
| 15 | 7.55턴 | 61% | 48% | 20% | 6% |
| 20 | 7.25턴 | 64% | 58% | 15% | 10% |

### 6. [신규] 굴림 개수 ↔ 위력 반비례를 선형으로 보정하면 안 된다

### 8. [반영 완료] 유진 승률 = 뒷면 값의 함수로 재서술
규칙 문서의 *"승률은 약 37.5%"*를 **조건부 표**로 교체했다. 앞면은 크리라 항상 이기므로 승률은 전적으로 뒷면 값 위치가 정한다:

> 교환 승률 = 0.25 × 1 + 0.75 × (뒷면이 적 굴림을 이길 확률) → 범위 아래 **25%** / 범위 바닥 **37.5%**(기준 배치) / 한가운데 62.5%

- **이 배치 자체가 유진 밸런싱의 1차 레버**임을 명시. 상수로 박아두면 조절 가능한 값이라는 게 묻힌다
- **축이 둘**임을 명시: *앞면 확률* = 처형 빈도 / *뒷면 값* = 평상시 교환 승률. 무기 설계 때 따로 잡을 것
- 적 설계 절의 "유진 37.5%" 인용과 도사림 "뒷면 값 상승" 항목도 같이 정정(스테일 방지)

### 9-b. [해소, 사용자 확정] 유진 뒷면 값 = 2
9번 갈림길에서 **뒷면 2**로 확정. 확정 원칙 *"유진의 비-최대값은 형편없어야 한다"*가 문자 그대로 성립하는 쪽(꽝일 때 적의 1에게만 이김).

- **뒷면 값은 무기 속성이 아니라 동전 자체의 속성**이라 세 무기에 공통 적용 → 표 전체 재계산:

  |---|---|---|---|
  | 빌드업형 | 50% | 2 / **6** | **50.0%** |
  | 기본 | 25% | 2 / 8 | **37.5%** |
  | 한방형 | 15% | 2 / 15 | **29.2%** |

- **빌드업형 앞면 값을 5 → 6으로 조정**했다. 뒷면 2 기준으로 정확히 50.0%(시스템 기준선)를 맞추기 위해서. 무기가 맞바꾸는 축은 *앞면 확률 ↔ 크리 위력*이지 뒷면이 아니므로 뒷면은 건드리지 않음
- ⚠ **한방형 29.2%는 검토 대상**: 구 43%에서 크게 떨어졌다. 방향은 의도대로(승률 낮고 처형 확실)나 폭이 큼. 게다가 굴림 3개 기준 크리 1회 이상 확률도 57.8% → **38.6%**로 같이 떨어져 **처형 신뢰도까지 낮아졌을 수 있음** → 위력 절대 스케일 확정 때 재검토
- 코인 절의 예시값(`기본위력 3 + 코인 5 = 3 또는 8`)도 `기본위력 2 + 코인 6 = 2 또는 8`로 정정. 표준편차도 2.17 → **2.60**(폭이 넓어져 양극단성이 오히려 강화됨)

### 9. [신규 발견] 무기 표 "기본" 행이 자체 모순
위 정정 중 검산하다 발견. 무기 표의 기본형 굴림 값 **3 / 8**을 적 d6에 대고 계산하면 **50%**이지 37.5%가 아니다(37.5%가 나오려면 뒷면이 **2**여야 함).

**약한 도사림(무료: 방어도↑ / 그 턴 합 판정값↑) / 강한 도사림(에너지 1: 캐릭터 고유).** "다리 슬롯이 매 턴 공짜" 문제 해소 + 확정돼 있던 다리의 핵심 선택(안정 방어 ↔ 큰 리턴)이 자원으로 실체를 얻음.
- **올라프 = 부위 약화 + 광기 직접 부여** (구 "최저 체력 부위 **파괴**"에서 개정). 파괴가 아니라 약화로 낮추고 광기를 도사림이 직접 줌 → **"부위를 태워 광기를 번다"가 파괴 없이도 성립**(구 설계는 광기가 *파괴 시* 오르는 패시브에 의존해서, 약화만 시키면 엔진이 멈췄을 것)
  - **자기 조절 장치가 공짜로 딸려옴**: 다리 약화 → 도사림 효과↓ → **태울수록 태우는 능력이 무뎌짐**
  - **파생: 불사의 분노가 "몰린 상태"가 됨** — 스스로 부위를 1개까지 몰아넣는 자발적 진입 경로가 사라짐(이제 적이 짓눌러야만 파괴). 자살 빌드가 없어지는 건 광전사 컨셉에 오히려 맞으나 발동 빈도는 크게 줄어듦
  - ⚠ **광기 가속 주의**: 파괴를 안 기다려도 되니 광기 3 도달이 빨라짐 → 출혈 교환당 2 → 임계 5까지 1.7합 → **정공법 무의미화 위험이 한 단계 커짐**
- **유진 = 무기 교체 / 약점 포착(앞면 확률↑) / 뒷면 값 상승** — 셋 중 유일하게 고유 도사림이 여러 갈래, 전부 "처형을 어떻게 성사시킬까"로 수렴
  - **[정정] "앞면 확률은 건드리면 안 된다"(7-19)를 철회**: 당시 근거는 *도사림이 공짜·매 턴 반복이라 크리율이 상시 변동값이 되어 처형 게이트 튜닝이 무너진다*였는데, **에너지 게이트로 반복이 제한**되면서 크리율이 기준선이 아니라 **스파이크**가 됨 → 오히려 "이번 턴 처형 노린다"는 텔레그래프. 근거 소멸이므로 철회
  - **무기 교체가 도사림으로 흡수** (같은 날 중간에 정한 "조준 단계에서 재굴림 스택 1 소모"는 폐기): 도사림이 선제 처리라 그 턴 합에 반영 + 슬롯·에너지 이중 비용이 기존 구조에 그대로 얹힘 + **재굴림 스택이 순수 재굴림 전용으로 남음**
- **김삿갓 = 살 내어주기**(뎀감 + 받아낸 피해의 뼈 획득량↑ — 기존 도사림이 곧 이것)
- **강한 도사림 2개를 한 턴에 겹칠 수 있음**(다리+머리, 에너지 전량) → 결투 없는 순수 빌드업 턴. 의도된 선택지

## 2026-07-19 — RNG 소스 3종 확정 + 라오루식 굴림 소모전

"적 슬롯 수"를 잡으려다 **그 앞에 미정인 게 두 겹 더 있다**는 게 드러나서, 캐릭터 RNG 소스부터 역순으로 내려왔다.

### 0. 출발점 — 적 슬롯 수를 정하려다 막힌 것
- 기세 바가 **"1대1 솔로 전투라 공유 바 하나"**로 정의돼 있는데 문서는 동시에 **다수 잡몹전을 전제**한다(유진 재충전의 "적 처치"가 다수전에서만 실효). **1대다에서 바가 몇 개인지 미정**
- 공유 바 하나로 두면 잡몹 3마리 × 1슬롯 = 플레이어 3히트와 상쇄 → **순이동 0 = 교착**(안티패턴). 유력안 = **적 1체당 바 1개**
- 사용자 판단으로 여기서 멈추고 **RNG 소스부터 확정**하기로 함 → 아래

### 1. [공백 발견] 세 소스 중 정의된 건 유진 하나뿐
`:67`·`:253`이 "캐릭터별 다른 RNG 소스(주사위/코인토스/슬롯머신)"라고 적어놨지만, 실제 메커니즘이 있는 건 유진(d4, 4=크리)뿐. **올라프 코인·김삿갓 슬롯은 이름표만 있고 본문에 한 줄도 없었음**

### 2. 김삿갓 = 친치로 (사용자 원안)
- 내가 슬롯머신을 "릴 3개 합산 + 홀드"로 설계했으나 **사용자가 "그거 주사위 상위호환 아니냐"고 지적 → 맞았음.** 릴 합산은 결국 주사위 여러 개 더하기고, 종 모양이 되어 **당시 올라프 코인 안(종 모양)과 충돌**까지 했다
- 사용자 원안은 애초에 **친치로**였음. 친치로가 단순 주사위합과 다른 결정적 지점 = **대실패(히후미)가 존재**한다는 것. 보통 주사위는 나쁜 눈이 "작은 값"일 뿐인데 히후미는 *오히려 잃는다*
- **→ 김삿갓만 대실패가 이득이 된다** (받아낸 피해가 1:1로 뼈). 육참골단이 굴림 층위에서 한 번 더 반복됨. 친치로를 김삿갓에게 준 결정적 근거
- **꽝 = "가장 작은 눈"으로 뒤집음**: 처음엔 가장 큰 눈으로 잡았는데 계산해보니 **꽝이 목의 완전 상위호환**(꽝 평균 5.33·하한 4 vs 목 평균 3.5·하한 1)이었다. 낮게 뭉친 조합이 히후미·시고로로 빠져나가 남은 게 위로 쏠리기 때문. 목은 친치로의 기본 판정이라 뺄 수 없으므로 방향을 뒤집어 꽝을 목 아래(평균 1.67)로 깔았음 — **사용자가 "그럼 목도 없애야 하는 거 아니냐"고 먼저 지적**
- **스트레이트 전부 2배 안은 폐기**: 123까지 2배로 만들면 **히후미가 사라져** 친치로를 고른 이유 자체가 없어짐. 2배가 13.9%면 대박이 아니라 일상이 되는 문제도 있었음

### 3. [대개정] 합 = 라오루식 굴림 소모전 (사용자 설계)
- 올라프 코인을 림버스식으로 굴리려다 **"올라프만 다른 절차를 쓰면 상대·모든 적의 굴림 구조까지 맞춰야 한다"**는 비대칭 문제가 두 번 걸렸음
- 사용자 안: **스킬마다 굴림 N개, 합에서 한 개씩 맞부딪혀 양쪽 소모, 남은 굴림은 일방 공격.** 모두가 "굴림 N개"를 갖는 공통 절차라 **소스만 다르고 절차는 하나**로 통일 → 비대칭 문제 소멸
- **"굴림 개수(교환 횟수)"와 "굴림 하나의 구성"이 다른 층위**임을 명문화 (친치로 3주사위 = 굴림 1개분)

### 4. [정정] 기본 교환 승률 = 50% (사용자 지적)
- 내가 페이싱 표의 "3히트 우위 = 5턴"을 **달성해야 할 목표로 오독**해 "교환 승률 65%가 기본선"이라고 역산했으나, **사용자가 "시스템은 절반으로 두고 다른 요소로 올려야지"라고 정정**
- 맞는 지적. 그 표는 *참조표*이지 목표가 아니고, 시스템이 공짜로 우위를 주면 ① 짓눌림이 클라이맥스가 아니라 일과가 되고 ② 발악(코너 장치)이 상시 발동한다. 우위는 **증강·아이템·스킬 강화**(기존 성장 4축)에서 나오는 게 맞음
- **50%가 오히려 코어와 더 맞음**: 소모전이 평균 0으로 상쇄되므로 **확정적으로 바를 미는 건 결투 푸시 +20뿐** → 기존 확정인 "결투 승리가 바를 움직이는 사실상 유일한 변수"가 진짜가 되고, 기세가 운이 아니라 **심리전**으로 움직임
- **내 "9히트 폭증" 우려도 과했음 (사용자 지적)**: 3슬롯 전 교환 전승 = 0.5⁹ = **0.195%(512턴에 1번)**. 최대치만 보고 분포를 안 본 것. 실제 평균 순이동은 0
- **파생 ① 짓눌림 빈도가 전투 길이에 종속**: 50%면 바는 표류 없는 랜덤워크(턴당 SD≈15). 5턴 전투 4% / 10턴 14% / 15턴 23% → **잡몹전은 바가 거의 안 쓰이고 보스전에서만 클라이맥스**. 의도한 그림이지만 전투 길이 = 적 체력·슬롯 수라 0번 과제와 직결
- **파생 ② 증강 flat 보정이 매우 민감**: 1~6 굴림 기준 위력 **+1→58% / +2→72% / +3→83%**. 곱연산 금지라 모든 보정이 flat인 만큼 **위력 범위의 폭이 유일한 완충장치** → 절대 스케일은 넉넉히 벌려둘 것

### 5. [교체] 올라프 ↔ 유진 소스 맞교환 (사용자 발견)
- 사용자가 코인을 **"교환마다 3 아니면 8"**(단일 코인, 이진값)로 제시하면서 **"이러면 올라프랑 유진 소스를 바꿔야 할 것 같은데"**라고 스스로 발견 → 계산해보니 정확했음
- 내가 앞서 코인을 "종 모양·안정형"이라 한 건 **코인 3개를 합산할 때** 얘기였고, 교환마다 하나씩 던지는 소모전 구조에선 **정반대**가 된다. 코인(3/8) SD **2.5** vs 균등 주사위(1~4) SD **1.12**
- 컨셉으로도 이쪽이 더 맞음 — **유진 = 코인**("개십운빨, 모 아니면 도"에 동전 던지기보다 맞는 게 없음) / **올라프 = 주사위**(출혈을 쌓아 확정적으로 터뜨리는 축이라 굴림이 얌전한 게 맞음)
- 결과적으로 셋의 변동성이 **한 축 위에 순서대로** 늘어섬: **유진(양극단) > 올라프(균등) > 김삿갓(고정)**

### 6. 유진 코인 = 앞면 25% (사용자 확정)
- 내가 "코인 2개(앞앞 25%/앞뒤 50%/뒤뒤 25%)"로 크리율을 맞추려 했으나, 사용자가 **"그냥 앞면 확률을 25%로"** → 더 단순하고 더 극단적(SD 2.17 vs 1.77). 중간값이 없고 **굴림의 3/4이 바닥값**이라 "비-최대값은 형편없게"가 문자 그대로 구현됨
- **크리율 25%는 구 d4와 동일 → 처형 게이트 무손상**
- **유진만 기본 승률 50%가 깨짐(약 37.5%) — 의도적**: 값이 바닥에 몰려 평균이 같아도 못 이김. 버그가 아니라 시작점이고, 유진 키트가 정확히 이걸 푸는 도구(재굴림/도사림/결투 고점보장)로 채워져 있음. 보정은 **굴림 개수를 넉넉히**(3개면 합의 57.8%에서 크리 1회 이상)
- **도사림 번역**: 구 "주사위 최소값 +1"은 코인에 최소값이 없어 성립 불가 → **"뒷면 값 상승"**. *앞면 확률 상승은 폐기* — 크리율을 건드리면 **처형 게이트 밸런스까지 같이 움직임**

### 7. 기타 확정
- **올라프 소모전 보상 = 출혈**: 남은 굴림 수만큼 출혈 추가 부여 → "바를 우회한다"가 굴림 구조에 새겨짐. ⚠ 튜닝 주의 — 남은 굴림 3이면 평타 한 번에 출혈 3이라 **2액션이면 임계 5 도달**, 어제 3→5로 올린 취지를 되돌림. 구조만 확정하고 수치는 열어둠
- **최대값의 특별함 = 유진 전용 (확정)**. 정확히는 *처형 게이트*를 뜻함 — 김삿갓 아라시는 큰 한 방일 뿐 파괴 루트가 아니고(김삿갓 파괴는 위세/뼈 전담), 올라프는 크리 없음
- **평타 크리·"유진 비최대값은 형편없게"는 이미 본문에 있었음** (`:332`, `:341`) — 새로 정할 게 아니었음

### 8. [정정] 올라프 출혈 = 이긴 교환 수 (같은 날 재설계)
7번의 "남은 굴림 수만큼 출혈"이 **작동하지 않는다는 게 드러나 폐기.**
- 소모전은 교환마다 *양쪽* 굴림이 같이 소모되므로 **남은 굴림 = |내 굴림 수 − 상대 굴림 수|**이고, **승패와 무관하게 개수 차이만으로 처음부터 정해져 있다.** ① 이겨도 출혈이 안 늘고 ② **굴림 수가 같은 상대에겐 통째로 죽고**(남는 게 0) ③ 다른 상대에겐 매 합 똑같은 상수. "크게 이길수록 출혈"이라는 의도가 아예 구현되지 않았음
- **→ 출혈 = 한 합에서 이긴 교환 1회당 1스택.** 승률 50% × 굴림 3개 = 합당 평균 1.5스택 → **임계 5까지 3.3합 ≈ 3~4액션**으로 기존 "정공법 3액션 내외"와 일치. 오늘 정한 50%·굴림 3개가 이미 그 근처를 가리키고 있었음
- 부수 효과: 출혈량이 합마다 0~3으로 흔들려 **주사위는 얌전한데 누적 결과는 출렁이는** 구조가 됨
- **결투는 가산형 채택 (사용자 확정)**: 배율형(교환당 2)은 합당 평균 3스택이라 **2합이면 임계 5**에 닿아 결투가 정공법을 대체함 → **교환당 1 + 합 승리 flat +1**(합당 평균 2.5)로 평타와의 격차를 완만하게. 임계 5의 무게가 지켜짐
- ⚠ 광기 3+는 교환당 2스택이 되어 합당 3스택 = **1.7합이면 임계 도달**, 구 모델보다 50% 빠름. 의도된 스노볼이지만 위세 경유와 겹치면 정공법이 무의미해질 수 있어 절대 수치 튜닝 때 함께 볼 것

### 9. 굴림 개수 배분 — 개수↔위력 반비례, 상한 없음 (사용자 설계)
- **캐릭터 단위 차등은 금지**: 굴림 총량 차이가 그대로 바 드리프트다. 슬롯당 1개 차이면 3슬롯 기준 **턴당 +15 = 짓눌림 5턴**(페이싱 표의 "완전 압도"와 동일) → 개수를 캐릭터별로 다르게 주면 "시스템은 우위를 안 준다"가 즉시 깨짐. **차별화는 소스가 이미 담당**(유진 양극단/올라프 균등/김삿갓 고정)
- **개수 ↔ 개별 위력 반비례**를 원칙으로 채택. 개수는 **스킬 단위 레버**로 씀
- **[정정] 내 "차이 최대 1" 제한은 폐기 (사용자 지적)**: 나는 *기세 중립*만으로 역산해 "차이 2는 위력으로 상쇄 불가(승률 100% 필요)"라 했으나, **위력 축(누적 피해)과 선제 파괴를 계산에 안 넣은 것**이었다. 사용자 지적 — "위력이 높다는 건 데미지가 높다는 뜻이고, 꼭 기세 바 관점에서만 보면 안 된다". 기세와 부위 체력은 애초에 분리된 두 축이므로 기세 손해가 곧 전체 손해가 아님
- **[신규 규칙] 합 도중 부위 파괴/처치 시 남은 굴림 소멸**: 사용자의 "1굴림 캐릭이면 후속타 받기 전에 파괴시키면 된다"가 **문서에 정의된 적 없는 규칙**이었음. 없으면 굴림 적은 쪽이 먼저 부수든 말든 후속타를 다 맞아 개수 차이가 순수 페널티가 됨. 명문화하니 **소수 고위력이 아키타입으로 성립** — "먼저 부수면 후속타를 통째로 지우고, 못 부수면 두들겨 맞는다". 남용 방지는 기존 게이트가 이미 함(부위파괴 = 짓눌림 전용 + 고유 파괴 루트)
- **중립 공식은 참조값으로만 유지**: 순 히트 = `n(2r−1) − d`, 중립 `r = (d/n+1)/2`. 2vs3이면 75%, 3vs4면 67%. 금지선이 아니라 "이 스킬이 기세 기준 몇 %에서 본전인지" 확인용
- **김삿갓 = 소수 고위력 쪽 (근거가 소스에 있음)**: 친치로 굴림당 평균 **+2.85** vs 올라프 d6 **+3.5** — **꽝 50%(평균 1.67)가 평균을 끌어내림.** 개별 위력을 높게 잡을 이유가 자연히 성립
- **파생 — 김삿갓 리스크 루프가 굴림 개수로 구현됨**: 결투=굴림 적게(밀려서 뼈 적립=받아내기) / 평타=굴림 많게(상쇄해서 안전=탈출구). 확정돼 있던 "평타=순수 탈출구, 결투=받아내며 충전"이 별도 규칙 없이 물리적 형태를 얻음
- 스킬별 기준 배분은 **미정** — 위력 절대 스케일이 없으면 근거가 없어서, 캐릭터 스킬 수치 잡을 때 같이 갈 것

### 10. 기세 바 개수 = 진영 대 진영 하나 (명문화, 원래 확정돼 있던 것)
사용자 확인 — **원래부터 아군/적군 하나로 정해놨는데 문서에 안 적혀 있었음.** 구 문구가 "**1대1 솔로 전투라** 공유 바 하나"여서 근거가 *적이 하나라서*인 것처럼 읽혔고, 그 탓에 오늘 아침 내가 "다수전 바 개수 미정"으로 판단해 **"적 1체당 바 1개"까지 설계를 밀고 갔음.** 근거를 진영 기준으로 정정.
- **개체별로 쪼개면 안 되는 결정적 이유**: **발악·위세는 "내 상태"인데 바가 여러 개면 내 상태가 하나로 정의되지 않는다.** 발악은 `B ≤ −70` 발동인데 A몹 +50 / B몹 −60이면 판정 불가. 김삿갓은 위세 푸시가 바 하나만 되밀어 **잡몹전에서만 정체성이 무너짐**
- **내 "교착" 논거도 이미 무효였음**: "공유 바면 잡몹 3마리와 상쇄 = 교착"은 **슬롯 하나 = 히트 하나였던 구 모델** 기준. 히트가 교환 승리에서 나오는 현 소모전에선 3마리전 = 9굴림 대 9굴림 = **1대1과 동일한 중립 랜덤워크**
- **다수전 압박은 굴림 경제가 담당**: 적 수가 공격 슬롯 수(3)를 넘으면 맞받을 슬롯이 모자라 일방 타격 허용. 2마리 +15 / **3마리 중립** / 4마리 −15 → **몹 수 = 난이도 다이얼, 3마리가 중립선**
- 집중포화 보상도 유지 — 한 마리 죽이면 적 굴림 총량이 줄어 교환 경제가 기움 + "합 도중 처치 시 남은 굴림 소멸"과 맞물림

### 2. 대신 진짜 이슈 발견 — 위세 ↔ 고유 파괴 루트 자원 충돌
구 위세는 "출혈 즉시 폭발(스택 소모) + 광기 초기화"였다. 그런데 올라프의 고유 파괴 루트는 *출혈 스택 + 결투 성공*이라, **위세를 쏘면 셋업이 통째로 날아간다.** 실질적으로 "위세는 셋업 완성 전에만 쓰는 스킬"이 되어 궁극기가 시그니처의 방해물이 되는 구조였다.

### 3. 해결 — 위세 = 피니셔가 아닌 "셋업 가속 엔진" (사용자 결정)
- **위세 개편**: 출혈 **3스택 부여** + 광기 스택만큼 추가 피해. **출혈 폭발·소모 없음 / 광기 초기화 없음 / 부위파괴 없음**
- **부위파괴는 오직 결투로만** 단일화. 위세는 파괴를 직접 하지 않고 *앞당기기만* 함 → 게이트 없는 2번째 루트가 생길 여지 자체를 제거
- 셋 중 유일하게 위세가 피니셔가 아닌 캐릭터가 됨 (유진=처형 피니셔 / 김삿갓=역전 피니셔 / **올라프=가속 엔진**). 딜 체감은 위세가 아니라 앞당겨진 결투 파괴가 가져감

### 4. ②번 동시 해결 — 출혈 임계 3 → 5 상향
①의 해법("위세가 출혈을 다수 부여")은 그대로 두면 ②의 "셋업이 너무 빠르다"를 악화시키므로 한 덩어리로 재배치.
- **파괴 임계 출혈 3 → 5**. 정공법(평타1 + 결투승리2)은 3액션 내외로 다시 무거워지고, 가속 수단은 위세(출혈 3)가 독점
- 결과: 셋업 총 무게 유지 + "위세를 태워 앞당길까" 결정 지점 확보 + "무거운 셋업" 서술과 수치 일치
- 광기 5스택·불사의 분노의 출혈 부여량 증가는 위세 없이도 빨라지는 스노볼 우회로로 남김

### 5. 광기 = 상시 양날 자원으로 성격 변경
위세의 광기 초기화가 사라져 전투 중 광기를 되돌리는 장치가 없어짐(초기화는 적 처치 시에만). 공격력↑와 받는 피해↑를 계속 짊어지는 구조 → "부위가 망가질수록 강해지지만 그만큼 위태로워지는" 광전사 컨셉과 일치.

### 6. ③번 해결 — 김삿갓 "합이 붙는 위세" 처리 시점
턴 순서(`위세 최우선 → 도사림 → 속도순 합`)와 "김삿갓만 위세를 슬롯에 장착해 합을 건다"는 규칙이 맞물리는 지점이 정의된 적 없었음. 위세 합이 턴 맨 앞에서 도는지, 합 단계에서 속도순으로 도는지.

- **확정: 장착 슬롯의 속도로 속도순 합 단계에서 처리** (위세 최우선에서 예외). 근거 ① 최우선 규칙의 존재 이유는 "장착·변신형 위세 효과가 *그 턴 다른 행동들에* 적용되게" 하는 것인데 김삿갓 위세는 그 자체로 완결된 한 방이라 해당 없음 ② 턴 안에서도 "한 합 더 받아내고 쏜다"가 성립(앞선 합에서 뼈를 더 쌓은 뒤 터짐) ③ 역전 푸시가 턴 뒤로 밀려도 손해 아님 — 리포지셔닝용이라 다음 턴을 유리하게 여는 형태가 오히려 자연스러움
- **구간 판정 시점 = 발동 순간의 누적 스택** (턴 시작 시점 아님). 위세 장착 슬롯은 그 턴 원래 스킬을 못 씀

### 7. 파생 확정 2건 (사용자 지적에서 나옴)
- **슬롯 배치 = 승패 베팅**: 위세 합에서 지면(받아내면) 재노출 피해가 그 한 방에 가산되므로, **빠른 슬롯=이겨서 피해 없이 안전 회수 / 느린 슬롯=일부러 받아내며 한 방 키움**. 체력이 대가라 자가 밸런스(저체력에서 욕심내면 터지기 전에 죽음). "살을 주고 뼈를 취한다"가 슬롯 배치 단계에서부터 손에 잡힘
- **위세 합 판정값에 뼈 스택 불관여**: 판정값 = 위세 스킬 기본 위력 + 속도 보정만. 스택이 들어가면 **크게 모을수록 합을 이겨버려 재노출 가산을 못 받는 역설**이 생기고 "느린 슬롯에 넣어 지기" 레버도 고스택에서 무력화됨. 기존 "위세 위력·회복·부위파괴는 소비 스택이 정하고 합 승부와 무관"의 대칭을 완성해 양방향 독립

### 8. ④번 해결 — 유진 패시브 "한번의 찬스" 재설계
"적용 범위 모호"로 적어뒀지만 파고들어 보니 **범위 문제가 아니라 작동 불가능한 죽은 텍스트**였다.
- 구 텍스트 = "주사위가 최대값이 안 나오면 한 번 더 굴림 (위세 스킬 관련 패시브)". **위세 한정으로 읽으면** 유진 위세가 애초에 *크리 확정*이라 "최대값이 안 나오는" 경우 자체가 없어 영원히 발동 안 함. **전역으로 읽으면** 1~4 주사위에 상시 재굴림이 붙어 크리 확률 25% → **43.75%** 폭증 + 평균 굴림값 상승으로 합 판정값·바 미는 양까지 부풀고, "주사위를 다른 캐릭터보다 낮게" 설계한 저점이 무의미해지며, 처형이 상시 루트가 됨. 양쪽 다 못 씀
- **재설계 (사용자 안)**: 재굴림 **1회 보유 / 굴림 결과를 보고 즉시 선택 / 위력 굴림 한정**(속도 굴림 제외 — 합 승패 직접 조작 방지). 횟수를 1회로 잠그니 크리 확률 상시 상승이 사라져 합 승률·저점 설계·위세 확정 크리가 전부 그대로 살고, 대신 "지금 판돈을 한 번 더 걸까"라는 결정 지점이 생김 = "모 아니면 도" 정체성 + 이름과 일치
- **재충전 (사용자 안)**: **적 부위 파괴 또는 적 처치** 시 재충전. 파티 누구의 파괴든 인정(올라프가 터뜨려준 부위가 유진의 다음 도박을 염 = 파티 플레이). **자가 부위 파괴는 제외**(올라프 도사림 자해로 무한 충전되는 남용 차단)
- **보유 상한 폐기 → 전투 종료 초기화 (같은 날 재조정, 사용자)**: 초안에서 걸었던 "최대 보유 1·누적 불가"가 **유진 전용 아이템(매 턴 재굴림 1회 충전) 설계를 원천 봉쇄**하는 게 확인돼 폐기. 상한이 1이면 이미 차 있는 턴마다 아이템 효과가 통째로 버려져 아이템이 성립하지 않음. 대신 **전투 중 누적 자유 + 전투 종료 시 초기화(다음 전투는 1회로 시작)** — 상한의 원래 목적이었던 *전투 간 이월*(잡몹전에서 쌓아 보스전에 몰아쓰기)은 초기화가 그대로 차단하므로 손실 없음
  - 튜닝 주의로 남김: 아이템 매 턴 충전을 안 쓰고 계속 쌓으면 후반엔 사실상 무제한 재굴림에 근접 → 아이템 빌드의 페이오프로는 의도된 것이나, 과하면 "언제 쓸까" 결정 지점이 사라져 패시브 정체성이 희석. 필요 시 넉넉한 상한(예: 3)을 노브로 도입 가능
- **루프**: 재굴림으로 크리 확보 → 처형(부위 파괴) → 재충전 → 다음 도박. *도박이 도박 밑천을 버는* 구조. 처형 게이트(우세 이상 바 + 크리)가 살아 있어 자동 연쇄는 아님
- 참고: "적 처치"는 다수 잡몹전에서만 실효(단일 적은 처치=전투 종료) → 주 재충전원은 부위 파괴. 보스전에서도 도는 쪽이 부위 파괴라 이 편이 맞음

### 9. ⑤번 해결 — 유진 평타 "수비" 정리 (5건 전건 해소)
구 텍스트 = "맞는 디버프 부여 + 공격&수비". 수비가 어색한 이유가 두 겹 — ① 방어·셋업은 **도사림 전담**이라 팔 슬롯 공격기가 침범 ② **평타 강화 축**(무조건 잔효과 + 위력 토큰)에 수비가 걸릴 자리가 없어 강화해도 뭐가 오르는지 성립 안 됨.

더 큰 문제는 **평타에 할 일이 비어 있었다**는 것. 올라프 평타=출혈로 고유 루트에 연료 공급 / 김삿갓 평타=순수 탈출구인데 유진만 정체성이 흐릿했다. 그런데 처형 루트 설명에 이미 답이 있었음 — "체력 높은 멀쩡한 부위는 **칩 셋업 필요**"라고 요구해놓고 그 담당이 정해진 적이 없었다.

- **확정**: 평타 = 낮은 위력 + **조준 부위에 "취약"(받는 피해 증가) 무조건 부여** + 처형 사거리를 만드는 **칩 셋업**. 최대값 뻥튀기는 유지
- 유진의 한 판 리듬이 닫힘: **평타로 부위 깎고 취약 걸기 → 바를 우세까지 밀기 → 크리로 처형**
- **안전장치**: 취약은 **균형(×0.4)에서 멀쩡한 부위를 바닥낼 수 있는 크기까지 올리지 말 것.** 구간 배율이 유진을 기세 바에 묶는 유일한 고리라, 취약이 세면 그 고리가 끊기고 처형이 바 위치와 무관해짐
- **무기 특화(검=출혈/둔기=속도↓/창=방관)와는 분리**: 평타 잔효과를 무기에 연동하는 안을 검토했으나 **무기 시스템 자체가 미정**(획득 경로·교체 여부·아이템과의 관계 전부 없음)이라 범위가 커짐 → 취약 고정으로 닫고 무기 특화는 별도 TODO로 세움

- **위세(300)** = 피니셔 효과 규모↑. 충전 속도·임계는 안 건드림(캐릭터별 충전 구조가 제각각이라 충전 효율은 축으로 안 씀)

### 3. 기세 바 v1 수치 전체 확정 (전부 임시·튜닝 대상)
좌표계가 통째로 비어 있던 걸 채움.
- **좌표계**: −100~+100 (0=균형, +=내가 미는 쪽). 1대1 공유 바.
- **구간 배율**: |B|<30 균형 ×0.4 / 30~70 우세 ×1.0 / 70~ 짓눌림 ×2.0(→+100서 ×2.5). 중앙 ±30 데드밴드로 균형 국면 보존.
- **미는 양 = 순수 위력 격차**(속도 제외 — 속도는 승패만 정함). 신승(격차 1~10)+10 / 명확(10~20)+25 / 대승(20+, 크리·45급)+40 / 발악 +60~70. (앵커=유진 사의 경 max 45)
- **차등 감쇠**(매 턴 0 쪽): |B|>30 → 12/턴 / |B|≤30 → 5/턴. → 리드가 안 끈적한 역동적 줄다리기, 기본 휴식=균형. (직전 "우세5·짓눌림12" 안에서 사용자가 뒤집어 선택)
- **발악**: B≤−70(바닥 30%) → 합 위력 +25(flat). 한 합에 +60~70 되밀어 단숨에 역전.
- **김삿갓 클러스터**: 만개 **k=1.2**(만개=1.2·maxHP, 각 구간 24%·maxHP, 매핑 % 0–24/24–48/48–72/72–96/96–120으로 갱신) / 회복 반환율 **0.4**(만개 단발 ≈0.48·maxHP·~80% 천장, 불사 차단 — 단 도사림 뼈 배수와 함께 튜닝: 2배면 creep 불사 위험) / 되갚음 계수 **0.7**(3구간 0.34·maxHP로 부위 바닥냄=조건부 파괴 성립) / 위세 푸시 4구간 **+100**·5구간 **+130(±100캡)** / 보호 floor **X=25**(발악 급등량 환산).
- 검산 통과: 3구간 되갚음이 부위 체력 바닥내 조건부 파괴 성립 / −70서 4구간 위세로 우세까지 완전 역전 / 만개 회복 ~80% 천장으로 불사 차단.
