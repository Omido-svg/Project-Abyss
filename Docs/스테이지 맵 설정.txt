5. 게임 콘텐츠
5-1. 스테이지 / 맵
•	맵 구조: 노드 기반 로그라이크 방식
[노드 기반 로그라이크]
    
ex) Like 젠존제, 슬더슬
•	진행 방식: 스테이지별로 상이한 전투를 통해서 파티를 성장?
           이에 따라서 최종 보스 스테이지에서 보스격파가 우선시됨

5-1. 스테이지 / 맵구성
노드기반
스테이지 기반 -> 3스테이지, 1스테이지, 2스테이지는 중간보스, 3스테이지 메인보스
각 스테이지별로 트리레벨 -> 차후
일반 전투 -> 거의 안벌림
골드 노드 
조우 노드 -> 랜덤 버프 or 디버프 
상점 노드 -> 증강 구입 (리롤)
체력 교환 노드 -> 골드 대신 체력을 소모해서 증강 구입
턴수 제한 -> 지정된 턴 내에 전투를 승리시 -> 증강 3개 획득
정비 노드

일반 전투
엘리트 전투
상점
모닥불(강화 Or 휴식(체력 회복))
물음표(엘리트 전투 or 선택지 or 모닥불)

노드 진행중 관리할 파라미터 -> 골드, 증강, 아이템, 노드 진행별 정신력 깎기
증강 -> 캐릭을 버프? -> 티어가 존재? 1티어, 2티어, 3티어
아이템 -> 특정 캐릭터 집중 버프 (덱의 컨셉을 정해주는 노드), 공용아이템 -> 각 스테이지 중간보스 클리어시 획득 가능
아이템 리롤시 그때 골드사용 해서 리롤시 골드가격이 1.5배씩 증가
골드 -> 증강, 아이템 2개
정신력 -> 노드 진행별로 조금씩 차오름, 
          이를 케어하려면, 선택지노드에서 줄이거나, 정비노드에서 줄이거나

최종 선택
일반 전투 
엘리트 전투 (골드 x2, 증강 1개 or 아이템 1~2개)
물음표(엘리트 전투 or 선택지 or 모닥불)
선택지 -> 구성?
근토리 -> 림버스 둥지 개념, 현대 디스토피아
방문자 (주인공) 
버프 디버프? 골드 뺏기 골드 얻기? 체력 뺏기 체력 얻기? 정신력 정화 or 터짐?
상점 -> 증강구입 -> 리롤 비용 1.3?
체력 교환 노드 -> 골드 대신 체력을 소모해서 증강 구입
	아군 전체 체력 깍아서 현재체력을 공동으로 차감
ex) 체력 5% 로 증강 하나 구입시 -> 아군 전체 체력 합 x 5% / 4 만큼 캐릭별로 
차감
턴수 제한 -> 지정된 턴 내에 전투를 승리시 -> 증강 3개 획득
정비 노드의 비중?
상점에서 스타레일은 리롤이 안됨, 정비에 있는 상점은 리롤이 됨
각 스테이지 보스진입 전, 정비노드에 무조건 진입해야함
정비노드 = 체력 채우기 + 상점(리롤가능)
보스 노드
	1스테이지
	2스테이지
	라스트 스테이지
