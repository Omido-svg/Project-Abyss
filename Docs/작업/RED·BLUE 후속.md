# RED·BLUE 후속

2026-09-07 굴림 개편(공격/수비 굴림 폐기 → 스킬 단위 RED/BLUE 색)의 파급으로 다시 정해야 하는 것들.

## 결정 대기 (구조 — 사용자)

### 견고 · 무장해제 재정의 — 규칙서 11.2
- 원래 힘 · 쇠약 = 「공격 굴림만」, 견고 · 무장해제 = 「수비 굴림만」이었다
- 공/수 구분이 폐기되어 힘 · 쇠약은 모든 굴림에 걸리는 것으로 읽었다(규칙서 반영). **견고 · 무장해제는 걸릴 굴림이 없어졌다**
- 같이 볼 것: 감정 증강 경외 3티어 「견고」 카드 — 경외 축은 현재 힘 · 신속만 적혀 있다(견고 축은 08-23에 「수비 굴림 1개뿐 = 판당 −3.0」으로 제외됐었다)

### 1스테이지 보스 스킬 A · B의 색 — 규칙서 12.5
- 09-06 확정 당시 A = 「수 · 공 · 공」(수비 굴림 포함). 09-07 개편으로 수비 굴림이 사라짐 → A · B가 RED인지 BLUE인지 정해야 한다
- 확정 당시 실측: 수비를 뒤에 두면(공공수) 굴림이 적은 상대에게 일방 단계로 밀려 소멸했다 → 위치별 효과를 가진 스킬은 **배열 순서가 실제 강도를 바꾼다**
- 시뮬 v3은 A · B 모두 RED로 가정해 돌린다

### 히후미 「수비 굴림을 쓰지 않는다」 지침 — 규칙서 19장
- 개편 전 지침. BLUE와 어떤 관계인지 재검토 필요
- 히후미 스킬 전부 색이 미배정 — 스펙 엑셀 · 시뮬은 RED로 가정
