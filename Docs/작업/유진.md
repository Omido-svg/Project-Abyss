### 세 무기 공통

- **한 발 물러서다**(BLUE 빛0 평타 · 방어도 +10) — −12.0 / −21.5 / −20.0으로 **평타 중 항상 꼴찌인데 판당 8~10회로 가장 많이 쓰인다.** 빛0이라 빛이 없을 때 계속 나오는데 값이 마이너스다
- **BLUE 결투 전반이 바닥** — 적설 −35~−49 · 낙일 −22~−24. 올라프와 같은 「우선 결투 자리에서 체력 피해 카드를 밀어낸 값」이되 폭이 훨씬 크다. 실제 용법(뒤쪽 슬롯)과 다른 틀이라 그대로 값으로 쓰면 안 된다
- **끝장을 보다(빛4)가 백우 · 적설에서 1위** — 재굴림 정책과 무관하다(재굴림 켜도 백우 +36.8 · 적설 +21.2). 살수의 감 전량을 위력으로 바꾸는 구조 자체가 세다
- **잡몹 열에서 여러 카드가 소수점까지 같다** — 잡몹은 결투를 안 내 **승리시 효과가 통째로 꺼지고 몸체만 남는다**(백우 퇴로 차단 · 마침표를 찍다 · 숨통을 끊다 · 소문을 내다 전부 +15.6 / +3.4). 잡몹 결투 열은 굴림 · 색 · 빛만 잰 값


### ✅ 끝장을 보다 — 위력 기준 빛 2로 고정 (09-17)
결투 1위였는데, 분해하니 **값의 거의 전부가 효과가 아니라 빛에서 나왔다**(백우 보스).

| 변형 | 값 | 사용/판 |
|---|---|---|
| 효과 없음 · 빛1 고정 | +12.4 | 7.5 |
| 효과 없음 · 빛2 고정 | +15.4 | 5.7 |
| 효과 없음 · 빛4 고정 | +28.8 | 2.9 |
| **효과 없음 · 빛4 + 누적 감소** | **+42.8** | 4.5 |
| 감 전환만(빛4 고정) | +31.1 | 2.9 |
| 현행 전체 | +43.3 | 4.2 |

- 살수의 감 전환 기여 **0.5pp**, 위력 배수 A는 1→3이 **2.7pp**뿐
- ⭐ **원인 = 유진만 위력이 빛에서 파생된다**(4.2 「빛 1 = 평균 위력 +2」). 「쓸 때마다 빛 −1」이 내는 빛만 깎고 위력은 원래 빛 4를 그대로 써서, **빛 1만 내면서 빛 4짜리 위력(+8)을 유지**했다. 올라프 닥치는 대로는 굴림 범위가 표에 박혀 있어 같은 문제가 없다 — **유진 전용 공백**
- 위력 기준별(백우 / 적설 / 낙일): 4 +43.3 / +27.6 / +6.8 · 3 +40.1 / +22.6 / +5.5 · **2 +27.4 / +13.2 / +4.7 채택(사용자)** · 1 +6.3 / +0.8 / +1.3
  - 사용 횟수는 4.2~4.8로 거의 안 변한다 → 순수 위력 몫. 채택값이면 백우 결투 1위 → 3위권
- 엔진: 효과 코드 `POWLIGHT,N`(위력 계산에 쓸 빛을 따로 둔다. 효과가 아니라 스킬 속성으로 흡수)
- **✅ [09-17 해소] 「위력 기준 빛 분리」는 이 카드 전용 각주로 확정** — 일반 규칙으로 안 못 박음. 지금 유진에서 비용이 변하는 카드가 끝장을 보다 하나뿐이라, 안 쓰이는 패턴을 미리 규칙서에 일반 조항으로 적을 필요 없다는 판단(사용자). 나중에 비슷한 카드가 또 생기면 그때 일반화. 엔진상으로도 POWLIGHT,N이 애초에 카드별 속성으로 구현돼 있어 추가 작업 불필요

### ⚠ 값으로 읽으면 안 되는 것

- ⛔ **환형(공격) · 환형(수비)의 적설 +47.2 / +43.3 · 낙일 +47.9 / +46.3은 폐기** — 환경 누수다. 환형은 무기를 백우 · 낙일로 바꾸는데, 적설 · 낙일로 보정한 환경은 그 무기들에게 훨씬 쉽다

  | 보스 부위 체력 | 백우 | 적설 | 낙일 |
  |---|---|---|---|
  | 100 (백우 기준) | .491 | .007 | .066 |
  | 58 (적설 기준) | **.977** | .520 | .258 |
  | 44 (낙일 기준) | **.999** | .777 | .521 |

  - 적설 환경에서 백우는 .977, 낙일 환경에서 백우는 .999다. **환형 값 = 무기 격차 × 보정표**이지 카드 값이 아니다
  - 환형을 제대로 재려면 무기별 보정을 안 쓰는 별도 틀이 필요하다(미해결)
- ⛔ **손에 익히다 세 무기 모두 0.00회 = 측정 실패** — 평타 측정 틀의 도사림이 노림수 · 웅크리기뿐이라 **환형이 로드아웃에 없어** 조건(지난 턴 환형 완료)이 영원히 거짓이다. 올라프 피의 맹세와 같은 종류 — 공급원을 넣은 별도 틀로만 잰다 [[skill-measure-single-swap]]
- **때를 앞당기다 0.0~0.4회** — 감 4를 모으는 일 자체가 드물어 거의 안 나온다(백우 0.0 · 적설 0.1 · 낙일 0.4). 값이 아니라 빈도 문제
