# 히후미

## 결정 대기 (구조)
- **반격 굴림에서 대실패(1 · 2 · 3)가 나왔을 때** — 자해 60 · 뼈 60 · 반격 굴림 +1이 또 붙는가(무한 연쇄 가능성), 아니면 값 0인가. 시뮬 v3은 값 0
- **짓눌림 대응 재설계 (09-14)** — 구 패시브 「짓눌림에서 받는 피해 1/2(발악 치환)」는 5.4가 짓누름 · 발악(판정값 +1)으로 전면 재설계되며 폐지. 히후미는 지금 남들과 똑같이 발악(판정값 +1)만 받음 — 자기 색깔의 짓눌림 대응을 새로 만들지, 이대로 둘지 결정 필요
- **이관 카드 셋을 히후미 색으로 감쌀지**
  - 빚지기(대여형 에너지 회복: 승리 시 빛 +1 즉시, 다음 턴 최대치 −1) — 올라프에서 이관
  - 체력 → 흐트러짐 전환 도사림(올라프 「흐트러짐을 삼키다」의 반대 방향) — 비율 미정
  - 「모든 것을 걸다」(도박형, 유진에서 이관 후보) — 스킬 또는 직업 아이템
- 「수비 굴림을 쓰지 않는다」 지침 — RED·BLUE 후속.md
- 스킬 색(RED/BLUE) 전부 미배정

## 수치 대기
- **평타① 「푼돈 걸기」 기본위력 12 → 13?** — 09-09 「평타도 곡선」 개정을 적용하면 곡선 12 + 빛 0 + 히후미 1 = 13. 표의 12는 구 평타 사다리 값
- 자기 거버너 — 「다음 턴 결투 위력 감소」의 감소량. 시뮬 v3은 임의값
- 도사림 C 「살은 내주지」 — 「다음 턴 받는 피해 증가」의 증가량
- 위세 2형 「올인」 — 배당(최고 결과에 따라 뼈가 어떻게 되는가)이 없다. 시뮬 v3은 「최고 18 이상이면 뼈 2배, 대실패 하나면 0」으로 근사
- 평타② 「과감한 판단」의 「완전 차단」 정의 — 시뮬 v3은 근사
