# 구조 결정 대기 — 사용자 · 코덱스 (2026-09-26)

클로드가 계산하다 막힌 곳 중 **구조(메커니즘 · 조건 · 제약)** 라서 사용자가 정해야 하는 것만 모았다. 수치는 여기 없다 — 수치는 클로드가 계산한다.
각 항목의 원문 · 근거는 캐릭터 작업 노트(`유진.md` · `올라프.md` · `히후미.md`)에 있다. 결정이 나면 규칙서 해당 문장을 고치고 여기서 지운다.

**우선순위** — ⛔ = 지금 계산을 막는다 / ⏳ = 계산은 되지만 결과가 바뀔 수 있다 / 📝 = 나중

---

## 공통

1. ⛔ **결투 게이트와 「사용시」** — 규칙서 3.3은 「결투 스킬의 효과는 결투 대 결투가 성립해야 쓸 수 있다」인데, 엔진은 **승리시 · 패배시만** 게이트로 막고 **사용시 · 전투 시작시는 막지 않는다**(원래부터 이랬다. 세 캐릭터 공통)
   - 어느 쪽이 맞나: (a) 규칙서대로 사용시도 막는다 → 엔진을 고치고 결투 사용시 카드를 전부 다시 잰다 / (b) 사용시는 게이트 밖 → 3.3 문구를 고친다
   - 유진 은신 보상 결투가 이 문제의 직격이다(아래 유진 1)
2. ⏳ **도사림 층** — 전투당 1회 도사림은 효과 수치를 끝까지 돌려도 보스 ±2pp(히후미 · 올라프에서 세 번 재현). 도사림을 「한 번 쓰는 보정」으로 둘지, 사용 빈도 · 효과 규모 자체를 바꿀지
3. 📝 공통 규칙.md의 기존 결정 대기(다리 조준 · 적 고조 · 빛 시작값 · 턴 종료 처리 순서 · 강화 2회차 배율 · 시작 지급 세트)

## 유진

1. ⛔ **은신 보상 결투 vs 결투 게이트** — 은신 부위의 슬롯은 적이 조준하지 못해 **합이 안 붙는다 → 결투 대 결투가 성립하지 않는다.** 3.3을 그대로 읽으면 은신 보상 결투는 **은신이 켜진 순간 효과가 없다.** 은신 결투 2장을 게이트 예외로 둘지(공통 1과 함께)
2. ⏳ **은신 재부여** — 이미 은신인 부위에 다시 걸면 덮어쓰기 / 누적. (엔진 파라미터, 기본 덮어쓰기)
3. ⏳ **퇴로 차단 「짓누름」의 방향** — 내가 누르는 중(+70 이상) / 상대가 나를 누르는 중(−70 이하). (파라미터, 기본 내가 누름)
4. ⏳ **성장 판단 단계 누적** — 집행처럼 앞 단계 효과를 유지하나. (파라미터, 기본 누적)
5. ⏳ **부위 배정** — 플레이어가 카드를 둘 부위 슬롯을 직접 고르나. 은신 보상 카드의 값이 여기 달렸다. 엔진은 속도굴림 순 자동 배정이고 이때 **보상이 켜지는 비율 0.62**(임시값 스모크)
6. ⏳ **엔진 해석 7곳 확인** — 끝장 풀 분배(남은 풀 ÷ 남은 굴림) · 공명 덫 강화(스택당 가산, 집행 4의 2배에는 안 곱함) · 잔혹한 마무리 추가타 위력(무기 코인 1회) · 「피해 처리 뒤」 트리거 · 표식 소비는 대상 부위에서만 · 성장 강화 = 대상 부위 표식 · 은신 예약은 다음 턴 시작. 자세한 문구는 `유진.md` 「엔진이 해석으로 정한 곳」
7. 📝 **은신 카드 4장 · 성장 · 손질하다의 색(RED/BLUE)과 빛** — 엔진은 임시로 부여 카드 BLUE · 보상 카드 RED · 성장 RED 빛1 · 손질하다 빛1
8. 📝 **성장 단계별 요구 진행도** — 집행 = 발화 수, 판단 = 감 소비량. 판당 값은 계측기로 나오지만 **런 단위 누적은 다전투 하네스가 있어야** 잰다
