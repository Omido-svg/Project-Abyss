# 빌야르

## 확정

### 틈을 파고들다
- RED 기본
- 파괴 태그
- 피해 후 이번 타격으로 대상이 새로 약화/파괴/흐트러짐0이 되면 추가타
- 추가타는 원래 1굴림 위력/범위 공식, RNG 새로 굴림
- 감쇠 없음
- 추가타는 일방타격
- 같은 적/부위 재선택 가능
- 각 추가타가 다시 조건을 만들면 연쇄
- 일반 타격은 한 번에 약화+파괴 불가, 처형 예외
- **빛 1**
- 추가타 대상 적 = **생존 적 중 무작위**
- 추가타 부위 = **생존 부위 중 무작위**

### 굳히기
- BLUE 유틸 결투
- 현재 적 출혈 **8 이상**이면 다음 턴 위력 +1
- 구 티어 사다리 폐기

### 피의 대가
- 모든 굴림/카드 위력 **-3**
- 최신 4,000×3: 보스 +2.8pp / 잡몹4 -1.8pp

### 상처를 지우다
- 강한 도사림, 빛1
- 자기 출혈 최대4 소비
- 실제 1~2 소비 → 이번 턴 위력 +1
- 실제 3~4 소비 → 이번 턴 위력 +2
- 자기 출혈0이면 효과 실패
- HP 게이트 없음

### 흐트러짐을 삼키다
- 강한 도사림, 빛1
- HP<70%
- 자기 흐트러짐20 소비 → 체력30 회복

### 블로토
- 강한 도사림, 빛1
- 자기 최저 HP 부위 약화
- 광기2
- 공포3

## 재측정

- 구 "이긴 교환마다 출혈" 삭제
- **광기 소비량 2 / 3 / 4** 비교
- 보스 + 잡몹4
- 사용 빈도 + 실제 광기 소비량 기록

- 강한 도사림, 빛1
- HP 게이트 없음
- 자기 출혈 최대4 소비
- 자기 출혈0이면 실패
- **소비한 출혈 1당 방어도 +8 / +10 / +12** 비교
- 보스 + 잡몹4
- 사용 빈도 / 평균 소비량 기록

### 피의 서약
- 강한 도사림, 빛1

- 이 카드의 재생이 이미 활성 중이면 사용 안 함
- 자기 출혈2
- **재생 4×3 vs 5×3** 비교

### 피로 사는 숨
- 약한 도사림, 빛0
- 자기 출혈2 → 빛1
- HP 게이트 없음
- 최신 기준 재측정

### 최후의 저항
- 강한 도사림, 빛1
- 지난 턴 종료 시 짓눌림일 때만
- 사용 시 이번 턴 공격 슬롯의 현재 속도 = 보정 후 최대치
- 속도 디버프 무시는 아님
- 보스 + 잡몹4
- 조건 충족률 / 사용 횟수 / 충족 시 사용률 기록

### 노려보기

- 이번 턴 모든 합 판정값 +1
- 다리 웅크리기12 기준 최신 재측정

# 명성

## 확정

### 숨을 죽이다
- 방어도 **12**
- 백우만 별도 보정하지 않음

### 노림수
- 강한 도사림, 빛1
- 이번 턴 코인 앞면 확률 증가
- **백우 +12%p / 적설 +8%p / 낙일 +2%p**
- 낙일 +2 체감 문제는 나중에 채용률/체감에서 다시 볼 수 있으나 현재 값은 확정

### 손에 익히다
- "지난 턴 환형 완료 후 첫 턴" 구조 유지
- 낙일 고정 체력 피해 **C = 6 확정**
- 백우 A / 적설 B / 살수의 감 N은 아직 수치 미정

### 은신 부여 결투
- BLUE 결투
- 전투 시작 시 1회
- 사용 부위가 비은신 → 다음 턴 은신1 예약
- 이미 은신 → 살수의 감1
- **세 무기 공통 1 / 1**
- 백우 최신 틀 재확인 필요

### 칼을 갈다 — 구조 변경
- 강한 도사림
- **빛1**
- 살수의 감 소비 삭제
- 조건 없음
- **다음 턴 신속 N**
- **N = 2 / 3 / 4** 재측정

### 손질하다 — 구조 변경
- 강한 도사림 · BLUE
- **빛1**
- 조건 없음
- 현재 무기를 손질 상태로 지정
- 다음 턴, 그 무기로 이긴 굴림의 **낙점 표식 추가량 +N**
- 환형해도 손질 상태는 원래 무기에 남음
- 다음 턴 종료 시 해제
- **N = 4 / 6 / 8** 재측정
- 무기별 반응이 크게 갈리면 그때 무기별 N 검토

### 기회를 엿보다 — 구조 변경
- 강한 도사림
- **빛1**
- 현재 열광 레벨만큼 살수의 감 획득
- 열광0 → 0
- 열광1 → 1
- 열광2 → 2
- 열광3 → 3
- 즉 **살수의 감 획득량 = 현재 열광 레벨**
- 이 구조로 재측정

### 선금 받기
- 강한 도사림, 빛1
- 이번 턴 코인 뒷면 값 **+2**
- 세 무기 공통 유지
- 최신 기준 재측정

## 재측정 / 진단

### 믿는 구석
현재 후보는 **백우2 / 적설4 / 낙일3**이지만 **최종 아님**.
원인 조사 완료 전 확정 금지.

기존 이상:
- 백우 cost2 성공률 보스 9%
- 적설 cost4 성공률 보스 22%
- 재굴림 OFF인데 더 비싼 적설 쪽 성공률이 더 높음

반드시 추적:
1. `유비무환` +1/턴이 세 무기에 동일 적용되는가
2. 재굴림 OFF 상태의 숨은 감 소비처(패보기/폴드/카드효과/자동)가 있는가
3. 활성 로드아웃의 감 소비처 및 전투당 소비량
4. 무기별 전투 길이, 시도 직전 보유 감, 턴당 감 획득, 소비원별 총량, 추가 획득원
5. 믿는 구석 전투 시작 시 1회 타이밍
6. 다른 소비처와의 처리 순서
7. 격리 실험: 유비무환 +1만 켜고 재굴림/패보기/기타 획득·소비 모두 OFF

### 끝장을 보다 — 신규 재측정 구조
구 구조(무기별 감 묶음 3/2/1 + 공통 위력+2)는 최종 아님.

테스트 구조:
- 기본 위력은 계속 **빛2 기준 고정**
- 표시 빛4, 사용마다 -1, 최소1 구조 유지
- **공통 살수의 감 3을 한 묶음으로 소비**
- 불완전 잔여 감 보존
- 묶음당 보상:
  - 백우: 모든 3굴림 **+2**
  - 적설: 모든 2굴림 **+3**
  - 낙일: 1굴림 **+6**
- 필요하면 구 구조와 A/B 비교

### 은신 보상 결투
구 3/1/8은 **최종 아님**.
동일 고정피해가 백우보다 적설에서 더 큰 pp 상승을 만든 원인을 진단.
최신 기준으로 다시 측정하고, 무기별:
- 은신 ON 비율
- 발동 횟수
- 발동 시 실제 추가피해
- 교환 승률 변화
- 표식 발화/처형/흐트러짐 등 후속 이벤트
기록.

### 은신 보상 평타
공통 +1 최종 아님.
특히 낙일 +1에서 과도하게 큰 반응이:
- 합 승리 시 상대 잔여 굴림 전부 삭제
- 처형 문턱
때문인지 확인.

무기별 기록:
- 은신 ON 비율
- 교환 승률 변화
- 낙일 상대 잔여 굴림 삭제 횟수
- 처형 횟수
- 발동당 실질 피해/방어 이득

### 폭발 덫
새 구조는 확정:
- 설치마다 독립 인스턴스
- 재설치로 기존 지속시간 갱신 안 함
- 턴 종료 각 인스턴스 지속시간 -1
- 표식44 발화 시 같은 종류의 살아 있는 모든 인스턴스가 **한 번에 함께 발동 후 전부 소비**
- 폭발 덫은 `생존 인스턴스 수 × 개당 고정피해`를 **한 피해 이벤트**로 처리

이미 10-07 측정이 존재한다면 우선 그 결과를 검증:
- duration2 / damage per instance 3이 유력
- 적설 보스 +4.2, 잡몹4 +3.2
- 백우 보스 +3.4
- 백우 잡몹4 / 낙일 반응 낮음
최종 확정 전에 최신 브랜치 기준 재현 여부만 확인.

### 공명 덫
새 독립 인스턴스/동시 소비 구조 동일.
발화 시 살아 있는 같은 종류 공명 덫이 1개 이상이면 **강화 발화는 1회만**, 강화량은 스택 배수 안 함. 참여 인스턴스 전부 소비.

현재 무기별 강화:
- 백우: 강화 발화 흐트러짐 증가
- 적설: 쇠약 추가
- 낙일: 고정 HP 피해 증가

기존 최신 결과가 맞는지 재현하고, 특히 적설만 최소값에서도 과도하게 강한지 확인.

### 현상수배
백우는 다음 구조로 재측정:
1. 굴림1 승리 → **다음 턴 지정**
2. 굴림2 승리 → **다음 턴 표식**
3. 굴림3 승리 → **다음 턴 신속**
- FIFO이므로 다음 턴 지정이 먼저 적용되고 뒤 표식이 같은 카드의 지정을 받게 한다
- 표식/지정 대상 부위는 예약 생성 시 고정
- 각 굴림은 서로 다른 부위를 잡을 수 있음

적설:
- 현행 쇠약1 / 속박1 유지

낙일:
- 현행 균열은 구조 미결. 이번 인계에서 임의 변경 금지.

# 측정 출력 요청

각 재측정은 가능하면 **보스 + 잡몹4**, 최신 공통 정책:
- 다리 = 웅크리기12 비교 기준
- 머리 자동 도사림 없음
- 머리 기본 공격
- 재굴림은 해당 실험에서 명시하지 않으면 OFF

출력:
- 승률 Δpp
- 사용/판
- 조건 충족률 또는 효과 발동률
- 자원 소비 카드면 실제 소비/판
- 후속 임계/연쇄 카드면 관련 이벤트 횟수
- 최소 3시드, 가능하면 4,000판×3

결과는 카드별로 **구조 이상 / 수치 조정 / 대역 안**을 구분해서 보고할 것.
