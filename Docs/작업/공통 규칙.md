# 공통 규칙 — 결정 대기

## 다리를 조준하면 — 규칙서 1.5
- 다리는 공격 슬롯이 아니라서 조준하면 항상 일방타격이 된다 → 늘 최적 표적이 될 수 있다. 무엇이 되는지 정의 필요

## 적 고조 · 열광 3 이후 — 규칙서 5.7
- 적도 고조를 갖는가 — 사용자 구상: *완전히 압도면 나만 충전, 우세 · 균형이면 서로 나눠 충전*
- 열광 3레벨 이후 고조가 주는 것이 없다(바의 출구). 극단 회복 · 빛 래칫이 v5에서 사라진 자리

## 빛 시작값 — 규칙서 7장
- 증강 · 아이템으로 최대치가 늘어난 상태에서 전투 시작 빛 = 새 최대치인가, 3 고정인가

## 피해 처리 순서 — 규칙서 10.2
- 흐트러짐 → 체력 순서는 09-14 창 범위 결정(D-09)에서 사용자가 확인했다. 3~7번(flat 감소 · 캐릭터 증감 · 버림 · 방어도)의 순서는 구 엔진 순서를 옮긴 것 — 확인해 둘 것
- 턴 종료 처리 순서(출혈 도트 · 재생 · 상태 만료 · 고조 정산)도 정본이 없다. 요약본에 (미정)으로 적어둠

## 스킬 강화 — 규칙서 15장
- 2회차 비용 배율(1.5배 유력)
- 평타 강화를 공통으로 할지 카드별로 할지

## 시작 지급 세트
- 캐릭터별 시작 카드(3 | 3 | 3 | 1 기준) — 세 캐릭터 전부

## 캐릭터 4~7
- 구현 대상 아님(더미 데이터로만). 캐릭터 4(흐트러짐 특화) 컨셉 메모는 구판 규칙서에 있다

## 기타 균형 확인
- 노려보기(판정 +1) ↔ 웅크리기(방어도 +12) 균형
- 위세는 현행 보스전 길이에서 판당 1회 남짓(첫 발동이 전투의 61~81% 지점, 구 엔진 실측) — 「더 자주」 류 효과는 값이 없다
