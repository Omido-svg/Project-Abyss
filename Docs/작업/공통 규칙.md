## 피해 처리 순서 — 규칙서 10.2
- 흐트러짐 → 체력 순서는 09-14 창 범위 결정(D-09)에서 사용자가 확인했다. 3~7번(flat 감소 · 캐릭터 증감 · 버림 · 방어도)의 순서는 구 엔진 순서를 옮긴 것 — 확인해 둘 것
- 턴 종료 처리 순서(출혈 도트 · 재생 · 상태 만료 · 고조 정산)도 정본이 없다. 요약본에 (미정)으로 적어둠

## 상태이상 시스템 통합 (09-17, 규칙서 11장) — ⭐ 큰 구조 과제
- 지금 크기형(11.2 — 숫자=부여량, 지속은 엔진이 1턴으로 고정돼 여러 턴 유지 불가)과 지속형(11.3 — 숫자=턴 수, 부여량은 고정 1)이 나뉘어 있고, 공포·지정 같은 캐릭터 전용 키워드는 둘 다 아닌 예외로 각자 만들어짐(공포=고정 −1·3턴 비누적, 지정=3턴+표식마다 +2)
- **제안(사용자)** — 림버스 컴퍼니처럼 모든 상태이상이 **부여량과 횟수(지속) 두 숫자를 독립적으로** 갖는 통일 템플릿으로 재설계(예: 균열 3/2 = 매턴 3만큼 · 2턴 지속). 계기는 "공포 효과를 수정하자"는 이야기에서 표기 정리(공포3=3턴 지속 표기 통일) 얘기가 나왔다가, 시스템 자체가 중구난방이라는 지적으로 확장됨
- **범위 큼** — 11장(크기형·지속형 구분) 전체 재작성 + 히후미·올라프·유진 기존 카드 수십 장이 전부 현 표기에 기대고 있어 재검토 범위가 넓음. 오늘(09-17)은 손 안 댐 — **작업 노트에 구조 과제로만 남기고 보류**(사용자)
- 착수 시 먼저 볼 것: 크기형이 왜 1턴 고정으로 잠겨 있었는지 경위(구현 단순화 목적이었을 가능성) · 전용 키워드 3종(공포·지정·표식) 중 어디까지 이 템플릿에 편입 가능한지(표식은 무기별 발화 상한이 있어 단순 부여량/횟수로 안 들어맞을 수 있음)
- **✅ [09-18 추가 논의] 재적용(재생처럼 값·지속 둘 다 있는 상태) 문제 — 「버프 큐」로 방향 확정.** 크기형은 1턴 고정이라 문제없고(11.1), 고통·공포는 고정값·비누적이라 문제없는데(11.3), **재생**은 회복량·지속 둘 다 변수라 재적용 시 합산해야 하는지 덮어써야 하는지 규칙에 빈 구멍이 있었다. 다키스트 던전식 "합산 후 비례 재계산"(6/5)은 계산이 지저분해 기각. **대안 — 각 적용을 독립된 큐 항목으로 넣고(예약·버퍼), 항목마다 자기 값·잔여 턴을 따로 돌리다가 매 턴 활성 항목 전부를 합산해 실제 효과를 내고 UI엔 항목별로 따로 표시.** 병합·비례 재계산이 통째로 필요 없어지고, 여러 장 겹치면 진짜로 세지고, UI도 항목별 나열이 오히려 더 명확함(많은 게임이 이미 이 패턴). ⚠ **상태이상 시스템 전체의 기반 구조** 수준 결정이라 코더한테도 따로 전달 필요 — **사용자가 나중에 직접 구조화 예정**, Claude는 대기
