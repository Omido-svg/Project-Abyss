## 상태이상 버프 큐 — 코더 전달 (09-21, 규칙서 11장)
- 버프 큐(독립 항목 · N 합산 · 항목별 T) · N·T 문법 · ∞ · 표시 `값 · 아이콘 · 남은 턴`은 09-19~20에 규칙서 11장 · 시뮬 엔진 · UI 문서(`튜토리얼.md`)로 정본화됨. 통합 과제 자체는 해소
- 남은 것: `Default-Battle-Test`(코더) 쪽에 이 상태이상 구조(수치형 / 값 없는 지속형 / 고유 누적, 독립 항목 합산)를 전달한 기록이 개발로그에 없다 — 전달 여부 확인
- 정본 11장에 아직 없는 상태: 도발 · 은신(부위형 턴형 마커, 09-19 (3) 배치 논의에만 등장) · 핏값(가칭, 뼈 획득량 증가) — 아래 각 캐릭터 노트 참고
- **✅ [09-21 사용자 결정] 「부정적 효과(디버프)」= 몸 전체(캐릭터 줄)에 붙는 상태만.** 부위 칸에 붙는 상태(출혈 · 자기 출혈 · 표식 · 지정 · 봉인 · 덫 · 시한 · 도발 · 은신)는 부정적 효과라 부르지 않는다. 귀결: **정화 계열 카드의 대상 = 캐릭터 줄의 부정적 효과** — 정화 A(평타) = 부정적 효과 종류 중 무작위 하나(그 종류의 항목 전부), 전체 정화형(결투 12) = 부정적 효과 전부. 부위형 상태는 정화 대상이 아니다(자기 출혈은 상처를 지우다 · 피의 맹세 등 전용 소비 카드가 처리). 나중에 부위형을 지우는 카드가 생기면 그 카드 문구에 범위(그 부위)를 직접 적는다
  - ⏭ 규칙서 11장에 반영 필요(용어 정의 한 줄 + 정화 대상 명시). 내 노트의 「자기 출혈 = 디버프」 류 표현은 이 정의와 어긋나니 반영 때 같이 볼 것
