# 쳇 측정 대기 — 아직 안 보낸 회차

쳇(ChatGPT)에 보낼 측정 지시문을 모아 둔다. **보내서 결과를 받으면 그 회차를 지운다**(결과는 캐릭터별 작업 노트에 적는다). (회차가 없어도 파일은 남긴다 — 쳇 측정을 거는 고정 위치)

- 번들 = 바탕화면 `abyss_sim_for_gpt.zip`(`abyss-workspace/tools/make_gpt_bundle.ps1` · `.sh`). **10-04 윈도우 번들(2차) = 10-04 구조 결정 · 추가 결정 엔진 · `yujin_batch` 배치 32 ~ 46 · `olaf_balance_probe --dosa-mode / --ids` · `validate_engine_1004` 포함** — 그 뒤 sim_py를 고쳤으면 다시 구워 올린다
- 받은 결과는 CSV · md 파일을 `Docs/스킬 측정 자료`에 넣는다
- ⚠ **10-04 (3) 결정 뒤 측정 기준선이 바뀌었다** — 머리 도사림 시뮬 기본 정책(적 공격 행동 2 이하면 머리를 두 번째 도사림에)이 켜졌고 측정 틀에 두 번째 도사림 칸(웅크리기)이 들어갔다. 이후 회차 값은 그 전 회차와 직접 비교하지 않는다
- 시간 제한에 걸리면 유진은 `--n 600 --ncal 300` → `--n 400 --ncal 200`, 빌야르 프로브는 `--n 1000` → `--n 600`
- `yujin_batch` 결과 CSV에 **조건문 · 조건 충족률** 열이 있다(측정 정책 변형). 정책 변형의 기준 = 같은 틀의 기준선(폴백 = 기준 카드)이라 `Δpp(틀 기준)`과 `Δ효과`가 같다

## 35회차 — 빌야르 도사림 전용 틀 도배 재측정 (명성 부분은 10-04 완료)

```
python -m sim_py.olaf_balance_probe --xlsm x --kind 도사림 --suite conditional --dosa-mode spam --ids OL-S06,OL-S07,OL-S10 --n 1000 --procs 4 --out olaf_dosa_cond_spam2.csv
olaf_dosa_cond_spam2.csv를 파일로 줘.
```

읽을 것 — 34회차 도배 측정이 실전과 같은 값으로 나온 도구 문제(변형에 박힌 조건을 도배 모드가 못 덮음)를 10-04에 고쳤다. **최신 번들에서만 제대로 돈다** — 결과의 조건문 열이 전부 `always`여야 정상. 10-04에 받은 `olaf_dosa_cond_spam.csv`는 34회차 파일 그대로였다(실전과 같은 값)
## 36회차 — 잡몹 조합 (10-04 (3) 종별 결투 성향)

```
python -m sim_py.mob_combos --char 올라프 --enemy 잡몹4 --n 500 --set "평타1=OL-B12"
python -m sim_py.mob_combos --char 유진 --enemy 잡몹4 --n 500 --set "결투2=YJ-D11"

각 줄의 조합별 승률 표(적 결투 시전 열 포함)와 마지막 「요약」 줄을 보여줘.
```

읽을 것 — 30회차(역할별 임시 확률) 대비 조합별 승률 · 「적 결투 시전/판」 변화. 혼합형 확률(돌격 50 · 강타 75 · 난타 25 · 중장 30 · 반격 60 · 구속 · 침식 50)은 임시값이라, 조합이 한쪽으로 쏠리면 그 종의 확률부터 본다

## 37회차 — 명성 공명 덫 · 폭발 덫 (강화 고정값 · 지속 턴)


읽을 것 — 38 = 공명 강화 고정값(백우 흐트러짐 25 / 50 / 100 · 적설 쇠약 1 / 2 / 3 · 낙일 피해 5 / 10 / 20, 스택 무관 · 지속 임시 3) — 27회차는 「스택당」 시절이라 폐기. 46 = 덫 지속 2 / 3 / 5(폭발 덫 스택당 피해 2 · 공명 덫 중간 강화). 로컬 맛보기(적설 100판): 공명 지속 2 / 3 / 5 = +24 / +33 / +31 · 폭발 덫 +2 / +5 / +5
