# 쳇 측정 대기 — 아직 안 보낸 회차

쳇(ChatGPT)에 보낼 측정 지시문을 모아 둔다. **보내서 결과를 받으면 그 회차를 지운다**(결과는 캐릭터별 작업 노트에 적는다). (회차가 없어도 파일은 남긴다 — 쳇 측정을 거는 고정 위치)

- 번들 = 바탕화면 `abyss_sim_for_gpt.zip`(`abyss-workspace/tools/make_gpt_bundle.ps1` · `.sh`). **10-01 맥에서 구운 번들이 배치 20 ~ 28 · `yujin_batch --dosa-every`를 담고 있다** — 그 뒤 sim_py를 고쳤으면 다시 구워 올린다
- 받은 결과는 CSV · md 파일을 `Docs/스킬 측정 자료`에 넣는다
- 시간 제한에 걸리면 유진은 `--n 1000` → `--n 600 --ncal 300`, 히후미는 `--n 1500` → `--n 1000`
