# 쳇 측정 대기 — 아직 안 보낸 회차

쳇(ChatGPT)에 보낼 측정 지시문을 모아 둔다. **보내서 결과를 받으면 그 회차를 지운다**(결과는 캐릭터별 작업 노트에 적는다). (회차가 없어도 파일은 남긴다 — 쳇 측정을 거는 고정 위치)

- 번들 = 바탕화면 `abyss_sim_for_gpt.zip`(`abyss-workspace/tools/make_gpt_bundle.ps1` · `.sh`). **10-01 맥 2차 번들 = 구조 결정 1 ~ 17 엔진 · `olaf_chain_1001` · `yujin_batch` 배치 29 · 30 포함** — 그 뒤 sim_py를 고쳤으면 다시 구워 올린다
- 받은 결과는 CSV · md 파일을 `Docs/스킬 측정 자료`에 넣는다
- 시간 제한에 걸리면 유진은 `--n 1000` → `--n 600 --ncal 300`, 히후미는 `--n 1500` → `--n 1000`

## 진행 상황 (2026-10-01 기준)

## 17회차 — 빌야르 틈을 파고들다 연쇄형 (10-01 구조 결정 15)

1굴림 RED · 약화 · 파괴 · 흐트러짐이면 다른 적에게 연쇄 추가타. 빛 · 기본위력은 (미정) → 엔진 임시(빛 1 · 공식 위력)에서 위력 ±3 · ±6 · 빛 0 / 2를 잰다

```
python -m sim_py.olaf_chain_1001 --xlsm x --out olaf_chain_1001.csv --kind 평타 --suite final --n 1000 --procs 2
olaf_chain_1001.csv 파일 + 변형 × (보스 · 잡몹4) Δpp · 사용/판 표. 잡몹3은 참고만.
「[올] 연쇄 추가타/판」 지표도 CSV에 있으면 같이.
```

읽을 것 — 목표 = **보스 ±5 안 · 잡몹4는 위여도 된다**(빌야르 다수전 특화). 위력 · 빛 중 어느 조합이 그 자리에 오는지

## 18회차 — 잡몹 새 행동 재측정 (10-01 구조 결정 6 · 10)

턴당 결투 수 배정 삭제(몹별 결투) · 치유사(응급 처치 / 공격 적중 시 플레이어 다음 턴 빛 수급 −1) · 지휘관(보급 다음 턴 최대 빛 +1 · 방진 · 기세 바 −K) 반영 뒤. 체력 = 역할 기본값(배율 100), **캐릭터별 보정 없음**

```
python -m sim_py.mob_combos --char 올라프 --enemy 잡몹4 --n 500 --set "평타1=OL-B12"
python -m sim_py.mob_combos --char 올라프 --enemy 잡몹3 --n 500 --set "평타1=OL-B12"
python -m sim_py.mob_combos --char 유진 --enemy 잡몹4 --n 500 --set "결투2=YJ-D11"
python -m sim_py.mob_combos --char 유진 --enemy 잡몹3 --n 500 --set "결투2=YJ-D11"
python -m sim_py.mob_combos --char 히후미 --enemy 잡몹4 --n 500
python -m sim_py.mob_combos --char 히후미 --enemy 잡몹3 --n 500
각 출력의 조합별 표와 마지막 요약 줄(평균 · 최소 · 최대 · 표준편차)을 그대로 붙여줘. 시간 제한이면 --combos 1-5 / 6-10으로 나눠서.
```

읽을 것 — 조합 2(딜러 둘 + 버퍼 둘)가 여전히 튀는지 · 캐릭터 셋의 잡몹4 평균 · 치유사 빛 압박 · 지휘관 지원 빈도

## 19회차 — 명성 현상수배 · 노림수 (10-01 구조 결정 12 · 13)

배치 29 = 현상수배 백우 표식 3 / 6 / 12 · 낙일 균열 1 / 2 / 3 · 현재값 / 배치 30 = 노림수 앞면 확률 5 / 10 / 15 / 20%p(도사림 매 턴)

```
python -m sim_py.yujin_batch --batch 29 --weapons 1 --n 1000
python -m sim_py.yujin_batch --batch 29 --weapons 2 --n 1000
python -m sim_py.yujin_batch --batch 29 --weapons 3 --n 1000
python -m sim_py.yujin_batch --batch 30 --weapons 1 --n 1000 --dosa-every
python -m sim_py.yujin_batch --batch 30 --weapons 2 --n 1000 --dosa-every
python -m sim_py.yujin_batch --batch 30 --weapons 3 --n 1000 --dosa-every
CSV를 yujin_I_1001.csv 하나로 합쳐 파일 + 변형 × 무기별 Δ효과 · 사용/판 표.
```

읽을 것 — 현상수배: 백우는 표식 변형만, 낙일은 균열 변형만, 적설은 현재값만 의미가 있다(다른 무기 변형은 그 무기에 안 걸린다). 노림수: **무기별로** ±5에 드는 값
