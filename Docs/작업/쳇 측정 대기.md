# 쳇 측정 대기 — 아직 안 보낸 회차

쳇(ChatGPT)에 보낼 측정 지시문을 모아 둔다. **보내서 결과를 받으면 그 회차를 지운다**(결과는 캐릭터별 작업 노트에 적는다). (회차가 없어도 파일은 남긴다 — 쳇 측정을 거는 고정 위치)

- 번들 = 바탕화면 `abyss_sim_for_gpt.zip`(`abyss-workspace/tools/make_gpt_bundle.ps1` · `.sh`). **10-04 윈도우 번들(2차) = 10-04 구조 결정 · 추가 결정 엔진 · `yujin_batch` 배치 32 ~ 45 · `olaf_balance_probe --dosa-mode / --ids` · `validate_engine_1004` 포함** — 그 뒤 sim_py를 고쳤으면 다시 구워 올린다
- 받은 결과는 CSV · md 파일을 `Docs/스킬 측정 자료`에 넣는다
- 시간 제한에 걸리면 유진은 `--n 600 --ncal 300` → `--n 400 --ncal 200`, 빌야르 프로브는 `--n 1000` → `--n 600`
- `yujin_batch` 결과 CSV에 **조건문 · 조건 충족률** 열이 있다(측정 정책 변형). 정책 변형의 기준 = 같은 틀의 기준선(폴백 = 기준 카드)이라 `Δpp(틀 기준)`과 `Δ효과`가 같다

## 34회차 — 후속 (24 · 25 · 29회차 결과)

```
python -m sim_py.yujin_batch --batch 44 --weapons 1 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 44 --weapons 2 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 44 --weapons 3 --n 600 --ncal 300
python -m sim_py.olaf_balance_probe --xlsm x --kind 도사림 --suite conditional --dosa-mode situational --ids OL-S06,OL-S07,OL-S10 --n 1000 --procs 4 --out olaf_dosa_cond_sit.csv
python -m sim_py.olaf_balance_probe --xlsm x --kind 도사림 --suite conditional --dosa-mode spam --ids OL-S06,OL-S07,OL-S10 --n 1000 --procs 4 --out olaf_dosa_cond_spam.csv
yujin_batch_44 CSV 세 개를 yujin_1004_34.csv로 합치고, olaf_dosa_cond_sit · cond_spam CSV 두 개도 파일로 줘.
```

읽을 것 — **손에 익히다** 낙일 C 4 / 6(현재 8 · 2배 16에서 +25.5 — 값의 대부분) · **은신 보상 결투** 백우 3 · 적설 1 / 2 · 낙일 10 / 12(25회차: 백우 ≈ 3 · 적설 ≈ 1 ~ 2 · 낙일 8에서도 +5) · **빌야르** 광기를 가라앉히다(광기 틀) · 상처를 지우다 / 자기 출혈 소비 방어형(자기 출혈 틀) — 29회차 표준 틀은 자기 출혈 공급이 없어 측정 불가였고, 광기를 가라앉히다는 `mad>=1`이 너무 자주 열려 −35 ~ −42
