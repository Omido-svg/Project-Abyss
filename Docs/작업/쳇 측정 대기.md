# 쳇 측정 대기 — 아직 안 보낸 회차

쳇(ChatGPT)에 보낼 측정 지시문을 모아 둔다. **보내서 결과를 받으면 그 회차를 지운다**(결과는 캐릭터별 작업 노트에 적는다). 파일이 비면 파일도 지운다.

- 번들 = `바탕화면\abyss_sim_for_gpt.zip`(`abyss-workspace/tools/make_gpt_bundle.ps1`). **09-30 밤에 구운 번들이 배치 20 ~ 28 · `hihumi_batch --var/--hp/--cond`를 담고 있다** — 그 뒤 sim_py를 고쳤으면 다시 구워 올린다
- 받은 결과는 CSV · md 파일을 `Docs/스킬 측정 자료`에 넣는다
- 시간 제한에 걸리면 유진은 `--n 1000` → `--n 600 --ncal 300`, 히후미는 `--n 1500` → `--n 1000`

## 13회차 — 히후미 후속 스윕 (7 · 8회차에서 대역에 못 들어간 두 장)

```
python -m sim_py.hihumi_batch --enemy 보스 --cards HF-B06 --hp 94 --n 1500 --var "HF-B06:BARSPEND:B=0"
python -m sim_py.hihumi_batch --enemy 보스 --cards HF-B06 --hp 94 --n 1500 --var "HF-B06:BARSPEND:B=1"
python -m sim_py.hihumi_batch --enemy 잡몹4 --cards HF-B06 --hp 94 --n 1500 --var "HF-B06:BARSPEND:B=0"
python -m sim_py.hihumi_batch --enemy 잡몹4 --cards HF-B06 --hp 94 --n 1500 --var "HF-B06:BARSPEND:B=1"
python -m sim_py.hihumi_batch --enemy 보스 --cards HF-B06 --hp 94 --n 1500 --var "HF-B06:BARSPEND:A=0"
python -m sim_py.hihumi_batch --enemy 잡몹4 --cards HF-B06 --hp 94 --n 1500 --var "HF-B06:BARSPEND:A=0"
python -m sim_py.hihumi_batch --enemy 보스 --cards HF-B08 --hp 102 --n 1500 --var "HF-B08:OVERLOAD:A=200" --var "HF-B08:OVERLOAD:B=8" --cond "HF-B08=bone_avail>=200"
python -m sim_py.hihumi_batch --enemy 잡몹4 --cards HF-B08 --hp 117 --n 1500 --var "HF-B08:OVERLOAD:A=200" --var "HF-B08:OVERLOAD:B=8" --cond "HF-B08=bone_avail>=200"
python -m sim_py.hihumi_batch --enemy 잡몹4 --cards HF-B08 --hp 117 --n 1500 --var "HF-B08:OVERLOAD:A=250" --var "HF-B08:OVERLOAD:B=8" --cond "HF-B08=bone_avail>=250"
각 줄의 출력 표(2줄)를 전부 모아서 보여줘.
```

읽을 것
- **기세 소비형 B06** — 위력 2에서도 보스 +15였다. 위력 0(B=0) = 바 −15만 남긴 값, 바 소비 0(A=0) = 위력 +6만 남긴 값 → 위력 몫과 바 몫을 가른다
- **자기 과부화형 B08** — 위력 8에서 보스는 대역 안인데 잡몹4 +20이 위력과 무관했다. 비용 150 → 200 / 250으로 올리면 잡몹4가 내려가는지
