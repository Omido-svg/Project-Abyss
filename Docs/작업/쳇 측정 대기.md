# 쳇 측정 대기 — 아직 안 보낸 회차

쳇(ChatGPT)에 보낼 측정 지시문을 모아 둔다. **보내서 결과를 받으면 그 회차를 지운다**(결과는 캐릭터별 작업 노트에 적는다). (회차가 없어도 파일은 남긴다 — 쳇 측정을 거는 고정 위치)

- 번들 = 바탕화면 `abyss_sim_for_gpt.zip`(`abyss-workspace/tools/make_gpt_bundle.ps1` · `.sh`). **10-04 윈도우 번들(2차) = 10-04 구조 결정 · 추가 결정 엔진 · `yujin_batch` 배치 32 ~ 46 · `olaf_balance_probe --dosa-mode / --ids` · `validate_engine_1004` 포함 · **10-04 (5) 재구움 = 빌야르 일괄 결정(새 도사림 코드 · 틈을 파고들다 같은 적 재공격 · 대상 적 스위치 · 파괴 태그)** — 그 뒤 sim_py를 고쳤으면 다시 구워 올린다
- 받은 결과는 CSV · md 파일을 `Docs/스킬 측정 자료`에 넣는다
- ⚠ **10-04 (3) 결정 뒤 측정 기준선이 바뀌었다** — 머리 도사림 시뮬 기본 정책(적 공격 행동 2 이하면 머리를 두 번째 도사림에)이 켜졌고 측정 틀에 두 번째 도사림 칸(웅크리기)이 들어갔다. 이후 회차 값은 그 전 회차와 직접 비교하지 않는다
- ⚠ **상황 조건 도사림 측정 함정(10-04 (5))** — 조건 거짓 → PASS면 머리 두 번째 도사림도 사라져 안 쓰인 카드가 +Δ를 받는다(빌야르 보스 +14.8). 도사림 카드 값은 `머리 도사림 정책 (0안씀/1두 번째 도사림)=0` + 같은 틀의 빈 도사림(조건 `never`) 기준으로 읽는다
- 시간 제한에 걸리면 유진은 `--n 600 --ncal 300` → `--n 400 --ncal 200`, 빌야르 프로브는 `--n 1000` → `--n 600`
- `yujin_batch` 결과 CSV에 **조건문 · 조건 충족률** 열이 있다(측정 정책 변형). 정책 변형의 기준 = 같은 틀의 기준선(폴백 = 기준 카드)이라 `Δpp(틀 기준)`과 `Δ효과`가 같다
