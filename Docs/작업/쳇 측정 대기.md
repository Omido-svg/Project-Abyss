# 쳇 측정 대기 — 아직 안 보낸 회차

쳇(ChatGPT)에 보낼 측정 지시문을 모아 둔다. **보내서 결과를 받으면 그 회차를 지운다**(결과는 캐릭터별 작업 노트에 적는다). (회차가 없어도 파일은 남긴다 — 쳇 측정을 거는 고정 위치)

- 번들 = 바탕화면 `abyss_sim_for_gpt.zip`(`abyss-workspace/tools/make_gpt_bundle.ps1` · `.sh`). **10-04 윈도우 번들(2차) = 10-04 구조 결정 · 추가 결정 엔진 · `yujin_batch` 배치 32 ~ 43 · `olaf_balance_probe --dosa-mode / --ids` · `validate_engine_1004` 포함** — 그 뒤 sim_py를 고쳤으면 다시 구워 올린다
- 받은 결과는 CSV · md 파일을 `Docs/스킬 측정 자료`에 넣는다
- 시간 제한에 걸리면 유진은 `--n 600 --ncal 300` → `--n 400 --ncal 200`, 빌야르 프로브는 `--n 1000` → `--n 600`
- `yujin_batch` 결과 CSV에 **조건문 · 조건 충족률** 열이 있다(측정 정책 변형). 정책 변형의 기준 = 같은 틀의 기준선(폴백 = 기준 카드)이라 `Δpp(틀 기준)`과 `Δ효과`가 같다

## 24회차 — 명성 손에 익히다 (환형 틀)

```
python -m sim_py.yujin_batch --batch 35 --weapons 1 --n 600 --ncal 300
yujin_batch_35.csv를 yujin_1004_24.csv로 파일로 줘.
```

읽을 것 — 환형 틀 = 매 턴 환형(공격)으로 세 무기를 순환한다(새 무기 첫 턴이 매 턴 열림). 무기별 값은 A(백우) · B(적설) · C(낙일)를 한 칸씩 2배로 올린 민감도로 읽는다. 시작 무기는 의미 없어 `--weapons 1`만

## 29회차 — 빌야르 도사림 (전투당 1회 틀 폐기 뒤)

```
python -m sim_py.olaf_balance_probe --xlsm x --kind 도사림 --suite effects --dosa-mode situational --ids OL-S03,OL-S04,OL-S05 --n 1000 --procs 4 --out olaf_dosa_sit_a.csv
python -m sim_py.olaf_balance_probe --xlsm x --kind 도사림 --suite effects --dosa-mode situational --ids OL-S06,OL-S07,OL-S08,OL-S10 --n 1000 --procs 4 --out olaf_dosa_sit_b.csv
python -m sim_py.olaf_balance_probe --xlsm x --kind 도사림 --suite effects --dosa-mode situational --ids CM-S01,CM-S02 --n 1000 --procs 4 --out olaf_dosa_sit_c.csv
python -m sim_py.olaf_balance_probe --xlsm x --kind 도사림 --suite effects --dosa-mode spam --ids OL-S03,OL-S04,OL-S05 --n 1000 --procs 4 --out olaf_dosa_spam_a.csv
python -m sim_py.olaf_balance_probe --xlsm x --kind 도사림 --suite effects --dosa-mode spam --ids OL-S06,OL-S07,OL-S08,OL-S10 --n 1000 --procs 4 --out olaf_dosa_spam_b.csv
python -m sim_py.olaf_balance_probe --xlsm x --kind 도사림 --suite effects --dosa-mode spam --ids CM-S01,CM-S02 --n 1000 --procs 4 --out olaf_dosa_spam_c.csv
CSV 6개를 파일로 줘(sit_a ~ c · spam_a ~ c).
```

읽을 것 — situational = 카드별 상황 조건(블로토 광기 < 2 · 피의 서약 체력 70% 미만 · 피로 사는 숨 빛 ≤ 1 · 광기를 가라앉히다 광기 1+ · 상처를 지우다 자기 출혈 5+ · 흐트러짐을 삼키다 체력 70% 미만 · 자기 출혈 소비 방어형 자기 출혈 1+, 거짓이면 웅크리기) / spam = 매 턴 강제. 조건 충족률 열을 같이 본다. 블로토 · 광기를 가라앉히다의 잠정 추천값(광기 1 · 승리 출혈 2)을 여기서 다시 고른다
