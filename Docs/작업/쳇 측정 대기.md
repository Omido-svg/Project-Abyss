# 쳇 측정 대기 — 아직 안 보낸 회차

쳇(ChatGPT)에 보낼 측정 지시문을 모아 둔다. **보내서 결과를 받으면 그 회차를 지운다**(결과는 캐릭터별 작업 노트에 적는다). (회차가 없어도 파일은 남긴다 — 쳇 측정을 거는 고정 위치)

- 번들 = 바탕화면 `abyss_sim_for_gpt.zip`(`abyss-workspace/tools/make_gpt_bundle.ps1` · `.sh`). **10-04 윈도우 번들(2차) = 10-04 구조 결정 · 추가 결정 엔진 · `yujin_batch` 배치 32 ~ 44 · `olaf_balance_probe --dosa-mode / --ids` · `validate_engine_1004` 포함** — 그 뒤 sim_py를 고쳤으면 다시 구워 올린다
- 받은 결과는 CSV · md 파일을 `Docs/스킬 측정 자료`에 넣는다
- 시간 제한에 걸리면 유진은 `--n 600 --ncal 300` → `--n 400 --ncal 200`, 빌야르 프로브는 `--n 1000` → `--n 600`
- `yujin_batch` 결과 CSV에 **조건문 · 조건 충족률** 열이 있다(측정 정책 변형). 정책 변형의 기준 = 같은 틀의 기준선(폴백 = 기준 카드)이라 `Δpp(틀 기준)`과 `Δ효과`가 같다

## 진행 상황 (2026-10-04 기준)

10 ~ 30회차는 결과를 받아 캐릭터별 작업 노트에 적었다(21 ~ 28 명성 · 29 빌야르 · 30 잡몹, 10-04). 남은 회차는 10-04 구조 결정 뒤 재측정(`구조 결정 대기.md` 「🔁 재측정 대기」).

## 31회차 — 명성 현상수배 굴림별 효과

```
python -m sim_py.yujin_batch --batch 39 --weapons 1 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 40 --weapons 2 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 41 --weapons 3 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 39 --weapons 1 --enemy 잡몹4 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 40 --weapons 2 --enemy 잡몹4 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 41 --weapons 3 --enemy 잡몹4 --n 600 --ncal 300
yujin_batch_39 · 40 · 41 CSV를 yujin_1004_31.csv 하나로 합쳐 파일로 줘.
```

읽을 것 — 무기마다 굴림별 효과를 한 칸씩 움직인다(백우 1굴림 표식 3 / 12 · 2굴림 지정 1 / 4 · 3굴림 신속 2 / 적설 1굴림 쇠약 2 · 2굴림 속박 2 / 낙일 1굴림 균열 1 / 4). 현재값(임시) 백우 6 · 2 · 1 / 적설 1 · 1 / 낙일 2. 무기별 패키지 Δ효과를 비슷하게 맞추는 게 목표. 19 · 20회차 값은 근거로 쓰지 않는다. 로컬 맛보기(150판 · 보스): 낙일은 균열 값을 바꿔도 같은 값(다이얼 무반응 의심)

## 32회차 — 명성 은신 보상 평타 (은신 틀)

```
python -m sim_py.yujin_batch --batch 42 --weapons 1 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 42 --weapons 2 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 42 --weapons 3 --n 600 --ncal 300
yujin_batch_42 CSV 세 개를 yujin_1004_32.csv 하나로 합쳐 파일로 줘.
```

읽을 것 — 은신 틀 = 은신 부여 평타 · 은신 부여 결투가 은신을 공급한다(은신 페어 실전 사용). 세 단계(백우 1 / 2 / 3 · 적설 2 / 3 / 4 · 낙일 4 / 6 / 8)를 한 번에 올리지만 무기마다 자기 값만 걸린다. `은신 켜짐` 열 = 보상이 실제로 켜진 비율. 25회차의 은신 보상 평타 행은 같은 카드의 현재값(임시 2 · 3 · 6)

## 33회차 — 명성 도사림 후속 (23회차 결과)

```
python -m sim_py.yujin_batch --batch 43 --weapons 1 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 43 --weapons 2 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 43 --weapons 3 --n 600 --ncal 300
yujin_batch_43 CSV 세 개를 yujin_1004_33.csv 하나로 합쳐 파일로 줘.
```

읽을 것 — 숨을 죽이다(현재 방어도 20 — 도배 적설 +21 · 낙일 +16 = 위험 신호) 방어도 10 / 15의 도배 · 실전. 칼을 갈다(실전 전부 음수) 신속 2 / 3. 손질하다는 새 조건(환형 예약 없음 + 대상 표식 10 / 20 이상)으로 처음 제대로 재는 실전 값. 기준 = 웅크리기. 로컬 맛보기(적설 150판): 숨을 죽이다 방어도 10 / 15 도배 −10 / +3 · 칼을 갈다 신속 2 / 3 −11 / −14 · 손질하다 −11

## 34회차 — 후속 (24 · 25 · 29회차 결과)

```
python -m sim_py.yujin_batch --batch 44 --weapons 1 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 44 --weapons 2 --n 600 --ncal 300
python -m sim_py.yujin_batch --batch 44 --weapons 3 --n 600 --ncal 300
python -m sim_py.olaf_balance_probe --xlsm x --kind 도사림 --suite conditional --dosa-mode situational --ids OL-S06,OL-S07,OL-S10 --n 1000 --procs 4 --out olaf_dosa_cond_sit.csv
python -m sim_py.olaf_balance_probe --xlsm x --kind 도사림 --suite conditional --dosa-mode spam --ids OL-S06,OL-S07,OL-S10 --n 1000 --procs 4 --out olaf_dosa_cond_spam.csv
yujin_batch_44 CSV 세 개를 yujin_1004_34.csv로 합치고, olaf_dosa_cond_sit · cond_spam CSV 두 개도 파일로 줘.
```

읽을 것 — **손에 익히다** 낙일 C 4 / 6(현재 8 · 2배 16에서 +25.5 — 값의 대부분) · **은신 보상 결투** 백우 3 · 적설 1 / 2 · 낙일 10 / 12(25회차: 백우 ≈ 3 · 적설 ≈ 1 ~ 2 · 낙일 8에서도 +5) · **빌야르** 광기를 가라앉히다(광기 틀) · 상처를 지우다 / 자기 출혈 소비 방어형(자기 출혈 틀) — 29회차 표준 틀은 자기 출혈 공급이 없어 측정 불가였고, 광기를 가라앉히다는 `mad>=1`이 너무 자주 열려 −35 ~ −42
