# 작업 노트

기획을 진행하면서 쓰는 곳이다. **규칙서(`Docs/전투 시스템 규칙.md`)는 확정 규칙만 담는 깨끗한 문서로 유지하고, 논의 · 후보 · 계산 · 실측 · 결정 대기는 전부 여기에 적는다.**

## 흐름
1. 논의는 여기서 한다 — 주제 파일에 마음대로 적는다(지저분해도 된다)
2. 결정이 나면 **규칙서의 해당 문장을 깔끔하게 고친다**(「(미정)」 표시도 뗀다). 요약본 · 스킬 스펙 엑셀 · 시뮬 스킬 시트에 같은 값이 있으면 같이 고친다
3. 무엇을 왜 정했는지는 **개발로그**에 남긴다
4. 여기서는 그 항목을 **지운다.** 파일이 비면 파일도 지운다 — 이 폴더에 남아 있는 것이 곧 미결 목록이다

## 규칙서에 넣지 않는 것
- 날짜 · 버전 · 「구 ○○ 폐기」 같은 이력
- 실측 수치 · 시뮬 결과 · 계산 과정
- 후보안 · 「검토 중」 · 사용자 구상 메모
- ⚠ 경고문 — 확정 안 된 칸은 **「(미정)」** 한 단어로만 표시한다. 값이 적혀 있으면 임시값이다
