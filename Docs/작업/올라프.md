## 09-25 최신 확정 — 활성 풀 · 트리거 동기화

아래가 현재 게임 투입용 활성 상태다. 이 문서 아래쪽의 이전 실측과 후보 기록은 당시 엔진·카드 풀의 참고 자료이며 현재 활성 풀이나 밸런스 근거로 사용하지 않는다.

**활성 풀**
- 평타 **11장** — 물어뜯기 · 방패벽 · 버텨내기 · 후려치기 · 몰아치기 · 다시 일어서다 · 감싸기 · 틈을 파고들다 · 선수치기 · 약점을 노리다 · 저며내기
- 결투 **17장** — 표준 · 끈질기게 · 단칼 · 미쳐물어뜯기 · 피의돌진 · 물고 늘어지기 · 제살깎기 · 물러서지않기 · 정면승부 · 굳히기 · 피의 대가 · 피의 맹세 · 닥치는 대로 · 명예로운 전투 · 일기토 · 중형 광기 소비 결투 · 대형 광기 전량 소비 결투
- 성장 **1계통** — 침잠 / 통제. 결투 17장과 별도 관리
- 도사림 **10장** — 웅크리기 · 노려보기 · 블로토 · 피의 서약 · 피로 사는 숨 · 광기를 가라앉히다 · 상처를 지우다 · 흐트러짐을 삼키다 · 최후의 저항 · 자기 출혈 소비 방어형
- `막아서기`는 폐기. `쪼개기` · `받아넘기기` · `필사의 일격` · `숨통을 조이다` 및 명시되지 않은 과거 후보는 활성 풀에서 제외

**트리거**
- `매칭시`는 폐기. 결투 성립은 결투 효과를 여는 공통 게이트다
- `전투 시작시`는 첫 굴림 전에 카드 구조를 확정해야 하는 명예로운 전투와 대형 광기 전량 소비 결투에만 사용
- `사용시`는 실제 굴림을 쓰기 직전 굴림별 발동. 일방타격 굴림에도 적용
- `승리시 · 패배시`는 실제 교환이 있을 때만 적용. 일방타격은 승패가 아니다
- 도사림은 `도사림 발동시`로 표기

**구조 핵심**
- 일기토는 조준 단계에서 대상 슬롯을 독점한다. 기존 조준 해제 · 대상 변경/취소 시 잠금 해제 · 자동 복구 없음 · 해결 단계에서 조준 고정
- 피의 맹세는 1굴림 사용시 자기 출혈을 전부 제거하고 구간별 보상을 적용한다. 10 이상 제거하면 기존 보상에 **처형**이 추가된다
- 광기를 가라앉히다는 광기→빛 전환을 폐기하고, 소비 성공 시 그 턴 승리 교환마다 추가 출혈을 주는 도사림으로 변경
- 상처를 지우다는 기준 미달 시 방어도 갈래를 삭제. 기준 미달이면 효과 없음
- 자기 출혈 소비 방어형은 HP와 무관하게 사용 가능하며 발동 순간 HP 50% 미만일 때만 출혈 제거·방어도 환산
- 성장 침잠 4단계의 구 전투 시작시 대량 획득·초과분 힘 전환은 폐기. 4굴림 사용시 광기·자기 출혈을 얻고 증가 후 만개면 추가 보상·위력 강화

**구현 상태**
- `스테이지 맵 기획_계산기.xlsm`의 VBA와 `sim_py` 모두 `전투 시작시` · 굴림별 `사용시` · 실제 교환의 `승리시/패배시` · `도사림 발동시`를 분리했다
- 일기토는 조준 단계에서 대상 슬롯을 독점하며, 구식 일방타격 포기 지표와 `일기토 겹침 회피` 정책은 제거했다
- 최신 활성 풀은 계산기 「시뮬 스킬」 시트와 엔진 데이터에 동기화했다. 수치 미정인 성장 7종과 광기 결투 2종은 보이되 선택할 수 없는 상태다
- 명예로운 전투의 특수 재굴림·종료 규칙은 코더 구현 결정 대기다. 현재 엔진은 양쪽 1굴림·동률 재굴림 임시 동작을 유지한다
- 트리거 정의가 바뀌었으므로 아래 과거 실측은 최신 밸런스 근거로 쓰지 않고 전 카드 재측정한다

- 공통 굴림 수 = **1단계 2 / 2단계 3 / 3단계 3 / 4단계 4**
- 공통 1단계 = 1굴림 기본 · 2굴림 **승리시** 광기 N + 자기 출혈 N + 상대 출혈 N
- 침잠 = 2단계 3굴림 **사용시** 만개면 강화 / 3단계 3굴림 **사용시** 만개면 자기 출혈 추가 + 강화 확대 / 4단계 4굴림 **사용시** 광기 · 자기 출혈 획득, 증가 후 만개면 추가 보상 · 위력 강화
- 통제 = 2단계 3굴림 **사용시** 광기 N 소비 성공 시 안정화 / 3단계 성공 시 자기 출혈 전부 제거 / 4단계 4굴림 **사용시** 소비 성공 시 전부 제거 + 제거량을 재생으로 전환
