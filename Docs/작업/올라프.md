# 올라프

## 결정 대기
- **일기토(결투, 09-14 신설) 엔진 구현** — 「내 다른 슬롯이 같은 상대 슬롯을 조준해도 일방타격 무효화」는 슬롯 배치를 다 정한 뒤에야 판정 가능한 조건이라, 3.1 합 성립 로직(합 없는 공격은 전부 일방타격)에 예외 분기 필요. 잡몹전(적 슬롯 1개)에서는 대가가 거의 항상 발동, 보스전(슬롯 2~4개)에서는 타겟 분산하면 거의 안 물 수 있음 — 의도된 텍스처(사용자 확인)
- **전부 되갚다(결투, 09-14 신설) 엔진 구현** — 「합 시작 시」 트리거(위세 충전과 같은 자리)에서 바 상태를 읽어 그 굴림 세트 전체에 위력을 얹는 효과. 위력·범위 수치도 아직 (미정)
- **최후의 저항(도사림, 09-14 신설) 엔진 구현** — 「지난 턴 짓눌림」 사용 조건 자체가 신규(다른 카드는 전부 무조건 사용 가능)라 정책 로직에 게이트 추가 필요. 「속도 무한」도 경외 3티어 「제물」과 동시에 아직 시뮬 v3 미구현 — 둘이 한 번에 같이 붙는 게 나을 수 있음
- **피의 맹세(결투, 09-14 신설) 엔진 구현** — 자기 출혈 티어(0~4/5~9/10+)에 따라 파괴 권한 자체가 갈리는 카드라, 고정 `skDestroy` 불리언 하나로는 못 담는다. 히후미 만개 반격의 `noWeakGate` 예외(`p3_core.bas` `Hit`)처럼 이 스킬 전용 분기가 필요 — 시뮬 v3은 현재 `SBLEEDVOW` 태그만 데이터에 넣어두고 미구현
- **만개 상태 적 처치 시 광기 초기화 조항** — 세부 확인 필요(규칙서 17.1)
- **필사의 일격(평타 9) 공식** — 「자기 부위 체력이 낮을수록 위력 상승」의 공식이 없다. 시뮬 v3은 임의 공식으로 근사
- 시작 지급 세트
