# 1. 히후미 공통 자원

## 뼈

* 실제 뼈 상한: **500**
* 뼈 구간은 **실제 뼈만** 기준으로 계산한다.
* 100당 1구간.
* 가불은 뼈 구간에 포함하지 않는다.

## 피격 적립

**피격 적립** = 실제로 받은 피해만큼 뼈를 얻는 히후미의 기본 뼈 획득 방식.

* 실제 피해를 통해 정상적으로 얻는 뼈만 피격 적립이다.
* 카드가 명시적으로 뼈 N을 직접 지급하는 것은 피격 적립이 아니다.
* 공통 대실패의 고정 뼈 60도 직접 지급이므로 피격 적립이 아니다.

## 핏값

> **핏값 N/T** — `피격 적립`으로 획득하는 뼈가 N만큼 증가한다.

예:

* 실제 피해 20
* 핏값 8
* 피격 적립 결과 = 뼈 28

직접 뼈 지급에는 적용하지 않는다.

## 가불

가불은 실제 뼈와 별개의 **턴 한정 임시 지불 자원**이다.

* 턴 종료 시 전부 소멸.
* 실제 뼈 상한 500에 포함되지 않는다.
* 뼈 구간 계산에 포함되지 않는다.
* 뼈 보유 조건/비용/만개 500 조건에서는 실제 뼈처럼 취급한다.
* 뼈 비용을 지불할 때는 **가불부터 우선 소모**, 이후 실제 뼈를 소모한다.
* 일반적으로 전액을 지불할 수 없으면 부분 지불하지 않는다.
* `체득` 등 효과로 가불을 실제 뼈로 전환할 경우 실제 뼈 상한 500을 적용하고 초과분은 소멸한다.

### 위세와 가불

히후미 위세에서 뼈를 참조하거나 소모하는 모든 경우에도 **가불 포함**.

* 도박수 전량 소모: 가불부터 전량 소모 후 실제 뼈 전량 소모
* 올인 베팅: 가불 포함
* 위세의 뼈 보유량/문턱: 실제 뼈 + 가불 기준

단, **뼈 구간은 여전히 실제 뼈만** 본다.

# 2. 공통 대실패

히후미 친치로 대실패 공통 규칙:

* 해당 굴림 확정 실패
* 자신에게 피해 60
* 뼈 60 직접 획득
* 반격 +1

대실패 자해 60과 뼈 60은 별개 처리다.

대실패 자해가 정상적인 실제 피해 파이프라인을 타는지 여부와 별개로, 명시된 뼈 60은 직접 지급이므로 핏값 대상이 아니다.

`운명을 흔들다`처럼 카드가 명시적으로 예외를 가진 경우에만 공통 대실패 규칙을 무시한다.

# 3. 반격

* `(반격)` 태그가 붙은 스킬로 **실제 교환에서 패배할 때마다** 반격 굴림 +1.
* 합 종료 후 모인 반격 굴림을 즉시 일방타격으로 처리.
* 반격 풀은 합이 끝나면 소진.
* 영구 반격 저장 자원은 없음.

결투 반격 위력:

> `8 + 실제 뼈 구간 + 1 + 친치로 값`

평타 반격 위력:

> `4 + 1 + 친치로 값`

반격 굴림에서도 공통 대실패 규칙 적용.
대실패로 반격 +1이 새로 생기면 현재 반격 시퀀스 안에서 계속 이어질 수 있다.

# 4. 도발

최신 공통 도발 규칙:

> **도발 N/T** — 도발된 부위는 현재 도발 N이 높은 순서대로 처리한다. 각 부위는 최대 N개의 적 공격 행동/슬롯을 해당 부위로 강제 유도한다.

* 공격 행동/슬롯 단위이며 굴림 단위가 아니다.
* 적 공격은 속도 높은 순서로 가져온다.
* 도발 N 동률은 무작위.
* 적 속도 동률도 무작위.
* 높은 도발 부위가 먼저 자기 N개를 가져간 뒤 다음 도발 부위가 남은 공격을 가져간다.
* 남은 공격은 원래 타겟을 유지한다.
* 공격 불가능한 부위는 그 시점에 유도 효과가 발생하지 않는다.

# 5. RED / BLUE

히후미도 공통 RED/BLUE 규칙을 따른다.

* RED: 이긴 굴림이 체력 + 흐트러짐 피해.
* BLUE: 이긴 굴림이 흐트러짐 피해를 주고, 체력 피해 대신 자신의 흐트러짐을 굴림값만큼 회복.

RED가 더 많은 것은 문제로 보지 않는다.
BLUE만으로는 전투를 끝낼 수 없기 때문에 RED 다수가 자연스럽다.

* 뼈 50을 지불해 침체 방지 가능

  * 가불 우선

`위세 바`라는 표현 금지. 반드시 **기세 바**.

## 도발형

* BLUE
* 2굴림
* `(반격)` 없음

사용:

* 선택한 자신의 부위에 **다음 턴 도발 N/T 예약**

각 굴림 승리:

* 다음 턴 `견고 N/1`
* 다음 턴 `핏값 N/1`

도발/견고/핏값이 다음 턴 함께 활성화되는 구조.

## 몸에 새기다

전 단계/양 트리 모두 RED.

### 공통

* 1굴림 시작
* 1단계 기본위력 15
* 1단계 실제 교환:

  * 승리 → 승리축 진행
  * 패배 → 패배축 진행
* 먼저 문턱에 도달한 축으로 2굴림 단계 진입
* 이후 트리 고정
* 일방타격은 성장 진행에 포함하지 않음
* 1→2→3→4굴림 성장
* 1~3굴림 단계는 턴당 1회
* 최종 4굴림은 턴당 2회

### 승리 트리

2굴림:

* `(반격)` 없음
* 완승 2/2 → 가불 N 획득

3굴림:

* 각 굴림 승리 → 가불 N 획득

4굴림 `체득`:

* 턴당 2회
* 각 굴림 승리 → 가불 N
* 합 종료 시 **완전 차단**이면 현재 보유 가불 전부 실제 뼈로 전환
* 이 카드에서 얻은 가불 + 다른 출처 가불 모두 포함
* 실제 뼈 상한 500 적용
* 초과분 소멸

### 패배 트리

`(반격)` 유지.

2굴림:

* 각 패배 굴림 → 직접 뼈 N

3굴림:

* 첫 패배 → 직접 뼈 N
* 두 번째 패배 → 직접 뼈 N
* 3굴림 전패 → 세 번째 뼈 보상 대신 반격 +1
* 결과적으로 3패 시 뼈 2N + 반격 추가

4굴림:

* 턴당 2회
* 1번째 패배 → 견고 N/1
* 2번째 패배 → 직접 뼈 N
* 3번째 패배 → 직접 뼈 N
* 4번째 패배 → 단독 보상 없음
* 4전패 → 반격 +1
* 이 시점 실제 뼈 + 가불이 만개 500 조건 충족 시 합 종료 후 반격을 만개로 발동 가능
* 추가로 뼈 N 지불 시 해당 반격 모든 굴림 위력 +1

# 8. 히후미 도사림 최신 구조

공용 `웅크리기`, `노려보기`는 기존 공용 규칙 유지.

## 포커페이스

* 강한 / 빛 1
* 이번 턴 받는 피해를 피격마다 N 감소
* 이번 턴 `핏값 M/1`

기존 `피격당 뼈 +4` 문구 삭제하고 핏값으로 통일.

## 뼈에 새긴다

* 강한 / 빛 1
* 이번 턴 **실제 교환마다 뼈 N 직접 획득**
* 승패 무관
* 일방타격 제외
* 피격 적립 아님
* 핏값 영향 없음

## 살은 내주지

* 강한 / 빛 1
* 사용 시 **실제 뼈 N 직접 획득**
* 다음 턴 자신에게 `균열 M/1` 예약
* 가불 지급이 아님

## 이 판 접지

* 강한 / 빛 0
* 뼈 N 소모 → 체력 M 즉시 회복
* 뼈 비용은 **가불 우선**
* 가불 사용 금지 예외 없음

## 도사림 D — 친치로 안정 상승형

사용 시 이번 턴:

* 시고로 확률 +N%p
* 아라시 확률 +N%p

자신의 모든 친치로 판정에 적용:

* 일반 스킬
* 반격
* 올인
* 기타 친치로 기반 효과

## 신규 확률형 도사림 — 양극화형

추가 확정.

사용 시 이번 턴:

* 아라시 확률 +N%p
* 대실패 확률 +M%p
* 시고로 확률 유지
* 증가분만큼 일반 결과 확률 감소

기존 D와 별도 카드.

## 도사림 E — 반격 위력 강화형

기존 `뼈 → 빛 +1` 도사림 E는 **폐기**.

신규 E:

* 강한 도사림
* 사용 시 이번 턴 발생하는 **모든 반격 굴림 위력 +N**
* 반격 굴림 수는 증가시키지 않음
* 반격이 발생하지 않으면 효과 소멸
* 기존 뼈 구간/친치로 계산은 그대로

## 도사림 F — 균열 + 핏값

기존 `피격 적립 ×1.5` 삭제.

최신:

* 사용 시 자신에게 `균열 N/1`
* 동시에 자신에게 `핏값 M/1`
* 둘 다 이번 턴

포커페이스보다 위험한 대형 피격 적립 카드.

## 상호 쇠약형

* 사용 시 자신에게 `쇠약 N/T`
* 동시에 상대에게도 동일한 `쇠약 N/T`
* 특정 상대 부위 조준 없음
* 피해 없음
* 상대를 선택하는 과정 없음

도사림 공통 규칙은:

> **도사림은 상대를 직접 조준할 수 없다.**

로 정리.

기존의

> 도사림은 자기 자신에게만 효과를 준다

라는 문구는 제거한다.

## 기세 바 태우기형

* 사용 시 기세 바 −N
* 이번 턴 `핏값 M/1`
* 0 리셋이 아니라 현재 기세에서 그대로 감소
* N/M 밸런싱 필요

# 9. 빚지기

히후미로 이관된 평타형 빛 회복 카드.

* 사용 시 빛 +1 즉시
* 다음 턴 시작 시 뼈 N을 지불할 수 있음
* 지불하면 페널티 없음

이 카드가 존재하므로 폐기된 도사림 E `뼈 → 빛 +1`을 부활시키지 말 것.

# 11. 기타 공통 용어 정리

## 봉인

> 슬롯을 사용할 수 없게 만드는 효과의 공통 명칭. 공용 상태이상은 아니며, 발생·대상·해제 조건은 각 스킬/캐릭터 규칙에 따른다.

기존 슬롯 행동 불가를 `과부화`라고 부르던 문구는 **봉인**으로 교체.

단, **과부화 트리**라는 스킬 계열명은 유지.

## 침체

> **침체 N/T** — 턴 종료 시 기세 바를 현재 침체 총합 N만큼 잃는다.

* 수치형 N/T 부정 효과
* 열기와 물리적으로 상쇄하지 않음
* 각각 독립 적용

`판을 엎다`에서 사용.

**⚠ [09-22 사용자 확인] 위 "기세 바"는 이 핸드오프 문서의 오타다 — 실제로는 기존 11.2 정의(턴 종료 시 위세 게이지 −N, 열기의 반대짝)가 맞다.** 침체는 이미 09-21에 코덱스가 11.2에 확정해둔 상태였고, 「판을 엎다」의 대가도 처음부터 위세 게이지를 깎는 것으로 설계된 것이었다(`히후미.md`의 09-21 실측 "자기 침체 3·3턴 → 위세 −9"도 이 기준). 규칙서 19.5(판을 엎다)는 침체의 대상을 명시하지 않고 11.2 정의를 그대로 참조하는 형태라 **수정 불필요** — 이 파일의 11절 문구만 오타로 기록해둔다.
