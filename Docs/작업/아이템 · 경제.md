# 아이템 · 경제

## 아이템
- 효과 값(대역) — 콘텐츠 뒤로
- **고유 축 = 위력 재산정** — 위력 +1의 값이 캐릭터마다 크게 달라(편차 18배) 히후미에게는 위력 아이템이 거의 안 걸린다
- 확률표는 획득 구조에 종속 — 선택 방식(무작위 1개 / 3중 1)을 바꾸면 확률도 다시
- 직업 아이템 — 아래 「직업 아이템 후보」(11-05 ~ 11-09 브레인스토밍). **아이템 중첩 확인 필수**
  - **캐릭터당 20종 확정(11-11)** — 런당 직업 획득 2.64개 그대로 · 특정 아이템을 보스 보상에서 만날 확률 약 60% → 30% · 전부 보는 데 약 8런. 아이템 하나에 빌드가 걸리지 않게(갈래마다 여러 장이 같은 방향)
- **공용 아이템 후보** — 전사의 함성(빌야르 22에서 이관): 위세를 발동한 턴 모든 굴림 위력 +1. 약해서 「발동하면 전투 끝까지 +1」로 키우는 안이 있다(미정)
