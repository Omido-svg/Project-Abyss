# 아이템 · 경제

## 아이템
- 효과 값(대역) — 콘텐츠 뒤로
- **고유 축 = 위력 재산정** — 위력 +1의 값이 캐릭터마다 크게 달라(편차 18배) 히후미에게는 위력 아이템이 거의 안 걸린다
- 확률표는 획득 구조에 종속 — 선택 방식(무작위 1개 / 3중 1)을 바꾸면 확률도 다시
- 직업 아이템 — 올라프 11종 후보(강화 / 전환 / 규칙 변경 3갈래) 평가 미착수 · 유진(표식 상한 조작 카드 후보) · 히후미 미착수. **아이템 중첩 확인 필수**

## 경제
- 체력 상점 환율 — 현재체력 1 = 2.5골드(잠정)
- **구 「증강 목록」 시트(런 영구 증강 · 일회성 증강 · 턴제한 전투 보상 · 상점 증강)의 존속 여부** — 감정 증강과 별개 층으로 남길지
