# 구조 결정 대기 — 사용자 · 쳇

**진짜 구조 문제 · 아직 규칙 자체가 정해지지 않은 항목만 둔다.** 결정이 나면 ① 규칙서 해당 문장을 고치고 「(미정)」을 뗀다 ② 요약본 · 명세 · `sim_py/data`를 맞춘다 ③ 개발로그 ④ **이 파일에서 그 항목을 지운다**(✅로 남겨 두지 않는다).

**구조 미결로 보는 것** — 규칙끼리 충돌한다 · 처리 시점을 정할 수 없다 · 대상 / 처리 순서 / 발동 조건이 안 정해졌다 · 효과가 구조상 절대 발동할 수 없다
**구조 미결이 아닌 것** — 구조는 정상인데 밸런스가 나쁘다 · 수치가 아직 없다(→ 아래 수치 TODO) · 특정 카드 사용률이 낮다 · 특정 무기만 잘 / 못 쓴다 · 시뮬 승률 편차 · 특정 잡몹 조합이 쉽거나 어렵다

> 지금까지의 결정(10-01 ~ 10-27 (4))은 규칙서 · 엔진에 반영하고 이 파일에서 지웠다 — 개발로그 참조. 이전 측정 · 밸런스 보고는 캐릭터별 작업 노트(`유진.md` · `올라프.md` · `히후미.md` · `잡몹.md` · `공통 규칙.md`)의 「이전 측정 · 밸런스 보고」 절로 옮겼다(이력).

- 세부 밸런스는 **실제 플레이테스트 뒤** 조정한다. 측정값은 참고자료이지 구조 변경의 자동 근거가 아니다
- 카드 · 무기별 사용률 편향을 허용한다. 모든 선택지를 비슷한 승률 · 가치로 맞추는 것을 목표로 하지 않는다(±5pp 대역 맞추기 폐기)
- 지금 조정하는 것은 **터무니없이 강하거나 약해서 구조 자체를 망가뜨리는 경우**뿐이다
- 10-09 방향(잡몹전 격차는 빌야르 · 명성 낙일을 올려서 맞추고 히후미는 낮추지 않는다)은 유지 — 근거 수치 `잡몹.md`

## 🔧 구조 미결

### ❓ 엘리트 · 보스 공격 스킬의 결투 여부 (11-02 (3) 엔진 구현 중 발견)
- 규칙서 12.5 · 12.6 표에 어느 스킬이 결투인지 없다. 12.1은 「적을 설계할 때 결투를 몇 개 내는가를 먼저 정한다」고 한다 — 플레이어 결투 효과(히후미 반격 · 뼈 · 만개 / 빌야르 출혈 · 광기 · 폭발 / 명성 표식 · 처형)가 전부 결투 대 결투 게이트 안이라서
- 결투인 적 스킬은 카드 효과 전체가 결투 대 결투 게이트 안이다(3.3 대칭 — 잡몹 처리). 그래서 결투로 정하면 광신도 B 고발 · D 증표 위력 / 파괴, 기계형 C · D 충전 효과는 플레이어가 결투로 받을 때만 켜진다
- 엔진은 스위치 `엘리트 결투 판정 (0전부 일반/1빛 드는 스킬/2전부 결투)`, 측정 기본 1(잡몹 문법). 세 안의 실측 차이는 `작업/적 · 콘텐츠.md` 엘리트 절 — 올라프 광신도 .018 / .064 / .404
- 정할 것 — 스킬마다 결투 여부(또는 「빛 드는 스킬 = 결투」 같은 일반 규칙) · 결투인 적 스킬의 효과도 게이트 안에 두는가. 이단 심문관(A · B · 고해 · 봉인 · 파괴기)에도 같은 질문

남은 「(미정)」은 수치 · 카드 풀 확충 · 시작 지급 카드 · 아이템 · 내성 배정 · 굴림 타입 · 엘리트 / 보스 콘텐츠 · 적 스킬 · 명명이다 — 구조 미결이 아니다.

**다음 작업 축 = 1층 전체 확인** — 1층 보스 이단 심문관(규칙서 12.5) · 1층 엘리트 2종(12.6)을 엔진에 구현하고 1층 전체 전투 기준으로 밸런스를 본 뒤 다음 스테이지로 간다. 남은 엘리트 4종 · 중간보스 2종 · 메인보스 2종은 그다음(규칙서 12.7)
