# 조우 이벤트 (물음표 노드) — 구상

11-24 사용자 구상. 규칙서 · 명세의 「조우 노드 — 선택지 40~50개, 조건 만족 시 큰 이득 / 미만족 시 작은 이득 (미작성)」을 채울 방향.

## 역할
- **반복 플레이의 지루함을 막는다** — 같은 런 구조라도 물음표에서 매번 다른 일이 일어난다
- **경로를 다양하게 만든다** — 물음표를 노리는 경로 · 피하는 경로가 갈리게
- **스토리 · 세계관의 일부를 보여준다** — 이벤트 문장 · 선택지로 세계를 조금씩 드러낸다(스토리 문서는 비공개 레포 `abyss-workspace/story/`)

## 이벤트 종류 (예시)
- **조건부 보너스** — 특정 아이템 · 스킬을 가지고 있으면 보너스(조건 만족 = 큰 이득 / 미만족 = 작은 이득)
- **엘리트** — 물음표에서 엘리트를 잡을 기회
- **대가 지불** — 체력 · 골드 등을 내고 아이템을 얻는다
- **도박** — 확률로 크게 얻거나 잃는다

## Unity 현재 상태 (11-24)
- 맵 생성 완료 — 물음표 노드는 들어갈 때 조우 / 골드 50:50(시드). 조우는 이벤트 내용이 없어 **빈 이벤트로 통과**한다
- 이벤트 내용이 정해지면 `RunFlowTestSession.EnterMapNode`의 물음표 분기에 이벤트 선택을 붙인다

## 정할 것
- 이벤트 목록(40~50개) · 각 조건 · 큰 / 작은 이득 값
- 물음표의 조우 / 골드 비율을 50:50으로 둘지(이벤트가 골드를 포함하면 골드 노드를 이벤트 안으로 흡수할 수도 있다)
