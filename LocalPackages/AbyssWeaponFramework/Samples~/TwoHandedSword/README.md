# Two-Handed Sword Sample

Weapon prefab markers:

- Grip_Main (Primary / Right)
- Grip_Support (Support / Left / IK enabled)
- BladeStart
- BladeEnd

The weapon root is parented only to the primary socket. The support socket is occupied and the second hand is driven toward Grip_Support by HumanoidWeaponIK or MappedWeaponIK.
